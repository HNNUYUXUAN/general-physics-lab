## 运行

需要Python 3.11以上、本机Wolfram环境。完整三稿构建还要求宋体和Times New Roman字体及可用的Wolfram前端。字体不随项目分发。

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e ".[test]"
python scripts/pipeline.py all --experiment course-03/rlc-resonance
python scripts/pipeline.py all --all
python -m pytest
python scripts/check_delivery.py --all
```

无参数的 `python scripts/pipeline.py all` 保留单摆兼容入口。可用 `python scripts/batch.py --list` 查看稳定实验标识。通过 `WOLFRAMSCRIPT` 指定WolframScript路径，`PHYSICSLAB_BUILD_ROOT` 可指定较短的临时构建根目录。

只重跑Python Notebook：

```text
python scripts/execute_notebooks.py --all
```

该命令把新执行结果保存在 `.build/notebook-checks/`，不覆盖已验收的成稿。公开自动检查明确记录字体或Wolfram环境缺失时的未运行状态。

## 数据、代码与验证

- `experiments/`：课程入口、规范CSV/JSON、来源记录、报告和Jupyter。
- `src/physicslab/`：公共工具与各实验的独立Python实现。
- `notebook/paclets/`：各实验独立Wolfram上下文、Notebook、测试和可安装包。
- `docs/`：[数据与方法](docs/data-and-methods.md)、[开发流程](docs/development.md)、[逐项验收](docs/delivery-summary.md)。
- `archive/`：本地原始资料及转换资料，不参与公开运行。

报告章节按各实验DOCX组织。Markdown/Jupyter使用标准LaTeX；Wolfram保存等价原生数学排版。图题在下、表题在上，图表采用白底黑线样式。单摆保留用户已批准版本。公共发布、许可证及公开材料清单另行处理。
