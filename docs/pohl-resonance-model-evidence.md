# 波尔共振：模型、参数与验证依据

## 线性扭振教学场景

采用线性回复和黏滞阻尼的欠阻尼扭振方程：

$$\ddot\theta+2\beta\dot\theta+\omega_0^2\theta=a_0\cos\omega t,\quad \theta(0)=\theta_0,\quad\dot\theta(0)=0.$$

$a_0=M_0/J$是归一化力矩，单位rad/s²；无需分别指定缺失的惯量和力矩。当前默认周期1.63s、衰减率0.12s⁻¹、归一化力矩0.02rad/s²、释放角2°，均为独立教学输入，不是对原大角数据的参数标定。

$$A=\frac{a_0}{\sqrt{(\omega_0^2-\omega^2)^2+(2\beta\omega)^2}},\quad\varphi=\operatorname{atan2}(-2\beta\omega,\omega_0^2-\omega^2).$$

完整解是稳态项$A\cos(\omega t+\varphi)$与衰减自由项之和。页面从真实零初速释放条件求系数；“观察稳态”推进到8/β秒，残余包络e⁻⁸，仍保留完整解。稳态扫频每点是独立稳态模型读数。

## 独立数值验证

Python/SciPy用DOP853同时积分角位移、角速度、输入功及耗散功，不调用浏览器解析解。36组参数覆盖周期、阻尼、驱动力矩和频率比边界；每组比较自由与受迫0–8/β全时段121状态，并检验$E-E_0=W_{in}-D$。稳态幅相另用二元实数线性方程解复响应，正峰衰减另核对对数斜率。统一绝对容差1e-8，最大状态误差约5.97e-11，能量平衡约6.23e-12。Node另验初值、共振90°相位、自由能量单调、正峰事件、来源隔离和无效输入。记录见 `docs/simulation/pohl-resonance-reference.json`。

## 原报告身份

12个自由周期点角幅度50.5°–160.5°；十个衰减峰从141°降至61°；十个受迫点最高141.9°。这些观测完整保存在独立输入JSON，不合入小角教学记录。衰减率的原数据拟合可说明该组包络规律，不能证明回复刚度在所有角度恒定。逐点参考周期为原稿所列参数，其中三点超过自由表幅度范围；源相位为两次稳定读数平均，未补造单次原始读数。

### 相位及峰频约定

以正的滞后角$\delta=\operatorname{atan2}(2\beta\omega,\omega_0^2-\omega^2)\in[0,\pi]$写$\theta=A\cos(\omega t-\delta)$，本页使用$\theta=A\cos(\omega t+\varphi)$，所以$\varphi=-\delta\in[-\pi,0]$。论文的单参数arctan不自动处理跨共振象限，不能直接用于本页全频扫描。严格90°发生在$\omega=\omega_0$；幅度峰在$\omega_r=\sqrt{\omega_0^2-2\beta^2}$，有限阻尼下二者有别，论文“近似相等”不改成严格等式。论文具体150°装置数据及仪器角分辨率不并入当前独立小角参数。
