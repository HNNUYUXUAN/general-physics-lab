# 旋光仪虚拟实验：模型、参数与验证依据

本稿依据已取得并核读的旋光线性关系与偏振投影文献[1]；条件材料参数保留原报告假设身份。

## 模型与测量

旋光关系为 $\varphi=[\alpha]lc$，其中c为g/mL、l为dm、比旋光率单位为°·mL/(g·dm)。理想双半视场分别由相差2ε的两个线偏振态构成，经过同一溶液旋转后投影到检偏器，强度分别为 $\cos^2(\theta-\varphi-\varepsilon)$、$\cos^2(\theta-\varphi+\varepsilon)$。ε=5°独立教学设定；这个等效Jones模型描述等亮判别，不重建真实仪器波片制造细节、视觉响应或杂散光。

等亮具有亮暗两个90°分隔的分支。基准与溶液都选择较暗分支，用180°周期的有向最短差求旋光角。当前全域最大旋光42°，无需跨越90°歧义；错误分支操作会保留其读数而不会自动纠正。

## 参数与源记录

默认比旋光率66.46与管长2dm沿用原作者的条件假定，默认浓度0.100g/mL为独立教学设定。域c=0.01–0.20g/mL、l=0.5–3dm、[α]=60–70；缺具体温度、波长及溶液材料身份，因此不推断实际材料温谱规律。

自动模型等亮角与用户手动选择的两次角度分身份保存，原报告5组双游标角度另作独立批次。源角差为绝对值，不能据此判断旋光方向；源管长并非独立实测，浓度只是给定管长与比旋光率下的条件反演。

## 独立验证

浏览器用旋转后的余弦平方；独立Python用二维Jones旋转矩阵乘两个线偏振输入并投影，brentq搜索暗等亮根。覆盖3浓度×3管长×3比旋光率的27场景、135方向、270视场强度值。Node覆盖旋光线性、暗/亮分支、180°周期、90°歧义与非法输入。原观测由单位复数相位求角差。

```text
node --test tests/optical-rotation-model.test.mjs
python scripts/validate_optical_rotation_simulation.py --repo-root . --output-root .
```

旋光与浓度的条件线性关系及偏振投影已核读，采用边界见下节；源作者未记录的比旋光率温度波长身份保留为未决参数，双半视场是明确推导的等效教学模型。独立验证JSON保存模型和源数据哈希、环境、容差与实际误差。
