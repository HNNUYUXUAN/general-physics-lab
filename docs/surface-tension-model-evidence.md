# 表面张力：模型、参数与验证依据

## 物理模型与操作

准静态吊环内外接触周界均提供竖直表面张力。以竖直向上接触切向为零接触角，两周界同角，理想峰值与膜重量为

$$L=\pi(D_i+D_o),\quad F_\alpha=\alpha L\cos\theta,\quad F=F_\alpha+m_fg.$$

传感器线性转换为 $V_1=V_0+F/K$、$V_2=V_0$；砝码标定 $V=V_0+mg/K$。操作完成砝码定标、读取拉脱前后电压对，再用简化式 $\alpha_{app}=K_{fit}(V_1-V_2)/L$ 反演。

附着液膜形状是状态示意，未用于定义脱离高度或拟合力—高度曲线。接触角和附着质量是明确的假设控制量，便于研究未满足完全润湿/忽略膜重时的结果偏移。

## 适用范围与验证

假设线性传感器和准静态、同接触角吊环，不模拟实际液面形状、拉脱动态或材料表面状态演化。教学膜重显式加入，但简化反演忽略它，故可检验偏差方向。标定传感器参数须一致，拉脱均值限定同一当前参数场景；每条原始电压对保留全部参数。

Python独立沿内外圆周数值积分表面力的竖直分量，附加膜重；再以线性代数最小二乘标定已知砝码电压。覆盖108组代表和边界组合，Node检查周界、润湿余弦、膜重偏差、零点抵消和混合标定拒绝。结果见 `docs/simulation/surface-tension-reference.json`。

### 传感器定义映射

论文$U=K_{paper}F$的K是电压/力；本项目转换系数$K_{lab}=\Delta F/\Delta U$是其倒数，内部单位N/mV。默认0.00036N/mV=0.36mN/mV，对应电压灵敏度2.777…mV/mN。页面定标直接拟合F–U，反演$\alpha=K_{lab}\Delta U/[\pi(D+d)]$。原校准与原温度参考值另保留身份。

论文p106表2的20℃72.75mN/m及25℃71.96mN/m是转引温度数据，未作为本装置精确校准。p108§2.4“周界小导致α偏小”与式6的分母敏感性相反；§2.3沾水的符号叙述也与其电压关系需另核。当前采用独立周界积分和显式附着质量推导，保留同一基线及未建模浮力、动态液面和真实接触线的边界。
