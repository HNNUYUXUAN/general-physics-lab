# 热功当量：模型、参数与验证依据

## 模型

均温量热系统采用恒定总热容C（cal/K）、换算参数J（J/cal）、恒电功P=UI和线性环境换热H（W/K）。

$$JC\dot T=P-H(T-T_a),\quad W=Pt=JC(T-T_i)+Q_{env}.$$

H为零时线性升温，否则温度以时间常数JC/H趋于 $T_a+P/H$。断电情景P=0从指定初温重新计算，不将其冒充同一次加热后的连续冷却记录。热交换积分可正可负，初温低于环境时系统先从环境吸热。

温升直线拟合得到 $J_{fit}=UI/(Ck)$，未自动修正散热；模型已知H时才可用积分 $Q_{env}$ 修正端点能量。C采用cal/K是单位前提，若用J/K后得到的是无量纲能量比。

## 全文核读

蔡晨、李朝荣、李英姿、王选：《电热法测量热功当量实验的新探究》，大学物理2016，35(5)：53–56。DOI：[10.16854/j.cnki.1000-0712.2016.0080](https://doi.org/10.16854/j.cnki.1000-0712.2016.0080)。四页全文已核读，p53–55数学和单位另经PDF渲染检查。

p53式1–5给总热容、电功、牛顿冷却与带驱动的一阶微分方程；p54式7–8给精确指数解及冷却回归。论文$K_p$单位s⁻¹，对应本项目$H/(JC)$；本项目H是W/K。其p55§2.2以水比热4.18J/(g·K)、内筒比热0.389J/(g·K)构成SI总热容，因此所报J≈1是无量纲能量比。本项目C采用cal/K，所报J采用J/cal；4.1868为原报告选择的教学卡标尺，不从该文J≈1换算或声称该文定义了cal。

### 公式核查与近似范围

冷却$\ln(T-T_a)$回归斜率为负，$K_p=-b_1>0$；采用论文p55的正确符号，不采用p54段落丢失负号的写法。温升的精确式$\Delta T=(T_\infty-T_0)(1-e^{-K_pt})$，线性近似相对温升误差应按$[K_pt-1+e^{-K_pt}]/[1-e^{-K_pt}]$衡量。论文式12/15以$e^{-K_pt}$归一的表达式不作为本页温升相对误差，500/530s条件也不当作通用最佳时长；本页直接求精确指数解并显示早/晚拟合偏差。论文中V、R、C和温度误差可忽略的预算属于其独立装置，本项目未移用。

## 集中热容公共模型

均温体系与恒温环境按线性热流交换时，$C_{eff}\dot T=-H(T-T_b)$，故$\tau=C_{eff}/H$、$T=T_b+(T_0-T_b)e^{-t/\tau}$。这是由该文牛顿冷却微分式和集中热容定义独立推得，适用于内部温度均匀、恒热容/换热系数的教学模型。线膨胀页τ=15s沿用这一结构，未将论文的具体热参或K移作金属杆标定。
