# 制流分压：模型、参数与验证

## 模型依据

理想电源和线性变阻器。制流为串联：$I=E/(R_L+XR_0)$。分压下滑片输出接负载，负载与下段$XR_0$并联，再与上段$(1-X)R_0$串联，$U/E=KX/[K+X(1-X)]$。

## 参数来源与适用范围

$E=5$ V、$R_0=1000$ Ω均为教学设定；$K=R_L/R_0=1$、$X=0.5$。软件开放E=0.1–12 V、R0=50–5000 Ω、K=0.1–10、X=0–1。原读数I/U未注明单位，原曲线仅有同尺度形状身份，绝对教学电量独立。

原报告CSV逐表保留在本页观测入口，来源路径和哈希沿原实验数据登记。模型教学值与原观测分别保存，不把原记录缺失值补成实测事实。

## 独立验证

270组电路用独立节点导纳矩阵求解，包括滑片两端极限；误差按 abs(error)/max(1,abs(reference)) 归一，预设容差1e-10。

检查结果和模型哈希见 [独立参考记录](simulation/current-voltage-divider-reference.json)。Node另检查解析算例、参数边界和所声明极限。

## 文献依据与范围

杨铁柱、周帅、潘峰：《基于LabVIEW的电表的改装与校准仿真实验系统开发》，大学物理实验，2021，34(5)：98–102。 [DOI](https://doi.org/10.14139/j.cnki.cn22-1228.2021.05.023)。全文已逐页核读，并查看关键公式的原页渲染。

p.100式(6)是含标准表、源内阻和可调电阻的串联欧姆关系。它支持本项目制流支路$ I=E/(R_L+XR_0)$的基础串联关系：将固定串联臂合为$R_L$、可调臂记为$XR_0$，并明确理想电源及读数端条件。这个映射不是对文中电表改装装置的复现。

带负载三端分压器来自项目原电路，按滑片节点独立写出

$$\frac{E-U_L}{(1-X)R_0}=\frac{U_L}{XR_0}+\frac{U_L}{R_L},\qquad 0<X<1.$$

令$K=R_L/R_0$消元即$U_L/E=KX/[K+X(1-X)]$，端点以连续极限处理；独立节点参考核对270组参数。论文没有讨论这一带负载滑片装置，也没有给出项目$K,X$参数。本项目绝对电源和电阻继续标为独立教学值。该参考条目的装置覆盖仅限基础串联关系；分压接线由原报告及明确的节点推导支持，专项滑片装置依据现由下节谢等2023全文逐条对应。

## 专项全文对应

谢钊洋、皮飞鹏、陈自强、陈译、陈欣：《可视化视角深度探究滑动变阻器接法中的两个疑点》，物理教学，2023，45(9)：17–20,11。全文已核读并检查原页公式。

谢等p.18图1、式(1)–(2)直接给出带负载分压。其滑动变阻器总阻$R_L$对应项目$R_0$、负载$R_x$对应项目$R_L=KR_0$，论文变量$u=l/L$对应项目电阻比例$X$，$v=R_L/R_x$对应$1/K$。由式(2)

$$\frac{U}{E}=\frac1{(1-u)v+1/u}=\frac{KX}{K+X(1-X)}$$

得到当前模型，$X=0$按连续极限取$U=0$，$X=1$取$U=E$。电阻丝均匀时，长度比例与电阻比例才等同；本项目$X$明确表示电阻比例。

p.19图4、式(3)–(4)的限流接入段位于滑片右侧，变量映射改为$u=1-X$、$v=1/K$，而不能复用分压的$u=X$。于是$U_L/E=K/(K+X)$，除以$R_L$得$I_L=E/(R_L+XR_0)$。论文两种接法都采用理想电表，实际负载保留在电路中；项目也忽略额外源内阻、仪表与接触加载，未忽略被调控负载。

独立节点求解270组情景检查两式；也可用分压器Thévenin等效$E_{\mathrm{th}}=XE$、$R_{\mathrm{th}}=X(1-X)R_0$核对。论文$E=10\ \mathrm V$及表1接法经验范围属于教学例子，未替换项目默认5 V、1000 Ω，也不作为硬性的线性误差上界。文中第4节功率比较未作为本页新增功能。原报告的绝对电源、总阻、读数单位仍未标定；这不影响已经明确定义的独立理想教学场景。
