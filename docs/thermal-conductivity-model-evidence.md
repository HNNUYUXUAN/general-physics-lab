# 固体导热：模型、参数与验证依据

## 一维热方程与边界

取原对称装置的中心面至加热面的半层，坐标x∈[0,R]。初温均匀T0，中心对称零通量，外表面输入恒热流。

$$\rho c\partial_tT=\lambda\partial_{xx}T,\quad T_x(0,t)=0,\quad\lambda T_x(R,t)=q,\quad q=U^2/(2Ar).$$

积分能量给出平均温升率q/(ρcR)。准稳态解是整体线性升温叠加抛物线剖面，因而两面温差qR/(2λ)，与原报告λ反演式和c斜率式一致。早期前沿尚未到中心，不能将该式当作任意时刻的精确反演。

## 数值实现与独立验证

以均匀单元中心有限体积离散扩散及外侧热流源，Crank–Nicolson解三对角系统。时间步使扩散比αΔt/Δx²≤0.4，保持离散升温非负及精确平均能量（浮点误差内）。中心/表面温度用二阶边界重构；每10s保存数值快照供播放和记录。

独立参考使用均匀初始、Neumann恒热流边界的Fourier级数：

$$T(x,t)=T_0+\frac{qt}{\rho cR}+\frac{qR}{2\lambda}(u^2-1/3)-\frac{2qR}{\lambda\pi^2}\sum_{n=1}^{\infty}\frac{(-1)^n\cos(n\pi u)}{n^2}e^{-n^2\pi^2Fo},\quad u=x/R,\ Fo=\lambda t/(\rho cR^2).$$

Python取200项，比较Fo=0.02/0.1/0.25与材料/几何27组组合；每组用20/40/80格，共243次网格计算，检验剖面二阶收敛和平均能量。Node另验边界升温方向、准稳态物性反演及非法读数。结果见 `docs/simulation/thermal-conductivity-reference.json`。

### 边界式核查

p17印式2使用时间导数等于qc/λ，左右量纲K/s与K/m不一致。Fourier热流定律和半层能量守恒要求空间边界$\partial_xT(R,t)=q_c/\lambda$，单位K/m；当前实现使用此边界。该更正与论文后续空间级数解一致，并由平均能量积分独立确认。论文Fo>0.5为其级数截断近似条件；页面显示实际温差与渐近值偏差，不把它当作材料普适判据。
