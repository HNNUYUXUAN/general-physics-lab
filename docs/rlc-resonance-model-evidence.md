# RLC 谐振：模型、参数与验证

## 模型与测量定义

采用集总、线性、恒幅正弦稳态串联 RLC 模型，电源输出电压以有效值定义。电感、电容视为理想元件，全部串联损耗用正实数电阻 $R$ 表示。电阻电压 $U_R$ 指这一等效总电阻两端的电压。

$$Z=R+\mathrm jX,\qquad X=\omega L-\frac1{\omega C},\qquad I=\frac U{\sqrt{R^2+X^2}},\qquad\varphi=-\operatorname{atan2}(X,R).$$

$$U_R=IR,\qquad U_L=I\omega L,\qquad U_C=\frac I{\omega C},\qquad P=I^2R.$$

电流相位相对于电源：低于谐振频率时为正（超前），高于时为负（滞后）。瞬时量按 $u(t)=\sqrt2U\sin\omega t$、$i(t)=\sqrt2I\sin(\omega t+\varphi)$ 显示。

## 半功率关系与反演

谐振时 $X=0$，$I_{\max}=U/R$，$U_{R,\max}=U$。半功率条件为 $I^2R=P_{\max}/2$，等价于 $X=\pm R$。

令 $\omega_0=1/\sqrt{LC}$、$d=R/L$，则

$$\omega_-=\frac{2\omega_0^2}{\sqrt{d^2+4\omega_0^2}+d},\qquad\omega_+=\frac{\sqrt{d^2+4\omega_0^2}+d}{2}.$$

低频根采用有理化形式，避免相近正数相减。恒等式为

$$f_-f_+=f_0^2,\qquad B=f_+-f_-=\frac R{2\pi L},\qquad Q=\frac{f_0}{B}=\frac{2\pi f_0L}{R}.$$

虚拟记录反演采用 $\hat f_0=\sqrt{f_-f_+}$、$\hat Q=\hat f_0/(f_+-f_-)$。几何平均关系对本模型成立，左右交点的算术平均一般不等于谐振频率。用户选频结果标为候选反演，同时列出两侧相对峰值比与1/√2的差，以及峰值电压相对源电压之比与1的差。实际参数改变后清除原自动定位身份；未改变参数的重复读取保留定位身份。只有接近 $1/\sqrt2$ 的两侧读数才具有半功率身份的物理意义。

## 独立验证

浏览器直接求阻抗和相位，独立 Python 参考使用复数节点导纳矩阵及 NumPy 线性方程求解器求中间节点电位和源支路电流，不调用浏览器公式作为参考输出。

覆盖 $L=50,100,200\ \mathrm{mH}$，$C=0.10,0.20\ \mu\mathrm F$，$R=20,88.38834764831844,400\ \Omega$，$U=0.1,1,5\ \mathrm V$ 及五个频率比，共 270 组。电流、电压相对误差、相位绝对误差及半功率归一化残差的预设容差均为 $2\times10^{-12}$。

另检查阻抗三角形的电压相量闭合、实功率、幅值线性缩放、半功率乘积与带宽恒等式、参数边界、不同情景记录隔离及原观测插值。实际运行结果和代码哈希见 [独立参考验证记录](simulation/rlc-resonance-reference.json)。

## 适用范围

当前实现交流稳态频率响应和稳态波形，不涉及接通瞬态。电源恒幅，元件线性且参数与频率无关。没有引入随机仪器噪声；虚拟记录反映模型值和用户选频。原报告未提供仪器限差和重复观测，因此原观测带宽法只报告估计结果，不构造完整不确定度。
