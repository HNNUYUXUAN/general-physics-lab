# 弦振动：模型、参数与验证依据

## 物理模型

均匀柔软弦、恒定张力、小振幅横向运动，两端固定。忽略重力挠度、弯曲刚度、阻尼和驱动瞬态。

$$\partial_t^2y=(F/\mu)\partial_x^2y,\quad y(0,t)=y(L,t)=0.$$

$$y/A=\sin(n\pi x/L)\cos(2\pi f_nt),\quad f_n=\frac{n}{2L}\sqrt{F/\mu},\quad \lambda_n=2L/n.$$

固定 $f,\mu$ 时 $\lambda\propto F^{1/2}$；固定 $F,\mu$ 时 $\lambda\propto f^{-1}$。页面选择固有模态并计算其频率；自动扫描反求满足指定频率的弦长。归一化振幅仅用于展示模态形状。

## 适用条件与读数

模型满足固定端边界。两条标线由用户移动至相邻波节，按 $\lambda=2|x_2-x_1|$ 保存；选择非相邻波节会产生操作偏差，原始标线位置完整导出。理想模态和标线记录分别拟合；混合线密度、重力或固定条件不成立时拒绝回归。

张力须近似均匀，实际实验中滑轮摩擦、驱动端边界与弦的伸长会影响结果。页面不模拟受迫响应幅值，动画用物理时间放慢100倍呈现，纵向坐标为归一化位移。

## 独立验证

浏览器使用解析本征模态。Python以固定端二阶差分拉普拉斯矩阵求本征值，再由张力和线密度换算频率；32、64、128、256空间区间逐级加密，覆盖弦长、质量、线密度边界和第1、2、6模态，共108组。最细网格相对误差阈值 $2.3\times10^{-4}$，加密误差比须大于3.9。验证结果与模型、脚本哈希见 `docs/simulation/string-vibration-reference.json`。

Node测试另外检查固定端及内部波节、周期性、密度与模态缩放、波动方程差分残差、测标关系、两个幂律指数及不相容记录拒绝逻辑。
