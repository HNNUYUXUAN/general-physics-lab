# 迈克尔逊干涉虚拟实验：模型、参数与验证依据

模型基础全文为张兴坊、刘凤收、梁兰菊，《迈克尔逊干涉仿真平台的设计与应用》，大学物理实验2023，36(1)：119–123，DOI：[10.14139/j.cnki.cn22-1228.2023.01.025](https://doi.org/10.14139/j.cnki.cn22-1228.2023.01.025)。全文5页已核读，p119/120/122/123实际渲染查看，关键关系见p120第1节及p122第3节；该文的完整等倾/非定域图样与本页直条纹近轴场景分开。

## 模型与操作

两臂返回的单色平面波等振幅、完全相干，动镜d产生往返光程2d；镜面相对小倾角α令波前近轴倾角约2α。观察面光程差 $\Delta(x)=2d+2\alpha x$，归一化强度 $I/I_{max}=[1+\cos(2\pi\Delta/\lambda)]/2$。固定x时每移动λ/2重复一次完整明暗周期，由 $\lambda=2(d_2-d_1)/N$ 反演。

张2023 p120第1节写虚拟空气膜光程差 $\Delta=2(d+x\tan\theta)\cos i$ 及强度 $i=i_0\cos^2(\pi\Delta/\lambda)$；其中$i$亦用于入射倾角，引用时本项目以$I$区分强度。p122第3节在入射倾角很小、角度相关光程项相对波长可忽略时讨论近似等厚直条纹。此处仅采用该近轴等厚限和相干余弦关系：$\tan\alpha\simeq\alpha$、$\cos i\simeq1$，得到本页线性光程。计数反演为固定位置相位增量 $\Delta\phi=4\pi\Delta d/\lambda=2\pi N$ 的独立推导；由Python未折叠相位求根检验。

本页设定本身是两返回平面波的近轴教学模型，没有采用论文的有限观察距离及曲率项。因此不将文中椭圆、双曲线或同心等倾环声称为本页输出。波前横向相位以$2\alpha$近似的误差受$\sin(2\alpha)/(2\alpha)$控制，α≤2mrad时相对偏差约2.67×10⁻⁶；这是独立小角度估计，不代表实际迈克尔逊光路的完整系统误差。

二维强度由相干模型计算，采用近轴平面波直条纹，不重建真实等倾环的有限光源、镜像位置与观察镜组。界面图示动镜运动按显示尺度放大。忽略振动、吸收、分束器相位漂移、偏振损耗、介质色散和机械回差。

## 参数与身份

默认λ632.8nm沿原报告指定参考，α0.25mrad是独立教学设定。软件λ400–700nm、α0–2mrad、相对动镜0–40μm；步进按钮每次λ/20用于观察，软件位移刻度不能作为实际微分头分度。N取1–100整数，自动N周期位移与手动实际计数分身份保存。手动期间反向移动会使当前区间失效；误数条纹保留为读数误差，不暗中修复。

原报告5组100条纹初末读数独立重算；632.8nm未附激光器校准证书，仅可作为指定参考值比较。原数据重复性分量不包含位移、计数及其他系统误差。
