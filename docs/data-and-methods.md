# 数据与计算方法

## 全项目输入与结果约定

实验登记表为 `experiments/registry.json`。各实验以自己的DOCX为主数据集；CSV保留读数及来源身份，JSON记录单位、仪器、参数、模型和缺失值含义。不同批次和讲义例值不混成独立测量。来源冲突、转录更正和条件性假设在各实验 data/ 与 results/ 中留痕。

新增实验结果采用 metrics、tables、series、notes 结构，分别记录输入哈希、代码哈希、运行环境和未修约计算值。指标容差按物理量尺度和实验声明设置；仪器信息缺失时不编造完整不确定度。两端独立实现算法，展示标签可以共享，计算数值不能复制。

以下各节记录已批准单摆的专用方法；其他实验的模型、参数与不确定度定义以其 experiment.json、报告和计算模块为准。

## 数据约定

每行计时记录对应一个长度组的一次重复测量，主键为 `(run_id, repeat_id)`。摆线长和直径在 CSV 中保留源表的 cm 数字及小数位；计算读取时转换为 m。`oscillations` 表示全振动次数。`experiment.json` 定义字段单位、模型、重复次数、仪器信息和对照容差。

源表均值、周期和报告结论不作为计算输入。缺失读数禁止按零补齐；未确认的仪器误差限在 JSON 中为 null。来源记录保留原文件路径、SHA-256、表格定位和整理说明，规范数据可独立运行。

## 拟合与不确定度

采用带截距 OLS：`T² = k ℓ + b`，`g = 4π²/k`。残差标准差使用 n−2 自由度。计时均值 A 类不确定度来自重复测量的样本标准差；回归重力标准误采用导数传播。两者分别报告，避免重复合成。尚无仪器误差限，因此不输出完整的合成或扩展不确定度。

共享球半径对各组有效摆长产生相同平移，含截距拟合的斜率对该平移不变。拟合暂不包含长度测量误差；正式误差变量模型需先获得仪器参数。

## 模型与验证

无阻尼单摆方程：`θ'' = −(g/ℓ) sin θ`。初始角度由度转换为弧度，初始角速度为零。Python 使用 SciPy DOP853，Wolfram 使用 NDSolveValue；数值周期由首个平衡位置过零时刻的四倍得到，并与完整椭圆积分独立比较。椭圆积分的参数为 `sin²(θ₀/2)`。

静态情景角度为 1、5、10、20、30、45、60 度，默认运动图为 20 度、1 m、10 s。重力参数使用实验拟合值；这组模型条件不代表原实验实际摆幅。

## 结果约定

两端 JSON 共享 `metrics`、`processed`、`simulation` 和 `amplitude_scan` 结构。指标值带单位；输入由相同文件的哈希标识，计算模块另记代码哈希。逐指标、处理表和扫描结果使用 rtol=1e−8、atol=1e−12；ODE 轨迹使用 rtol=1e−6、atol=1e−8。atol 使用对应指标的声明单位。

误差比较基于未修约数值。报告构建检查两端输入和代码是否仍为当前版本，校验成功后写入结果。`.build/` 保存临时预览与本地检查，发布成果保存必要的静态图及真实输出。
