# 声速：模型、参数与验证依据

## 两种定位模型

驻波振幅极大定位使用理想单模声路的多次往返几何级数。若有效往返幅度因子r∈(0,1)，忽略换能器额外频率响应，归一化复振幅为

$$H_{cav}=(1-r)\sum_{n=0}^\infty r^n e^{-i(2n+1)kL}=\frac{(1-r)e^{-ikL}}{1-re^{-2ikL}}.$$

其振幅极大在L=jλ/2。相位比较法另设低反馈的单程情景 $H_{phase}=e^{-ikL+i\phi_0}$，同相位置L=(j+φ0/(2π))λ。两情景不把相位法当作同一强反馈腔的简单线性相位测量。

使用相邻或已知跨越标序回归L(j)得到λ，再求c=fλ。双踪与李萨如图均由复振幅计算，电子恒相位影响绝对同相位置，不改变同类复现间隔。标尺比例误差共同影响两法，常数零点由截距吸收。

原20个读数是已由位置换算的波长，完整位置序列未保存；网页自动位置属于独立模型记录。原波长全部保留，不删除9.34mm点。两法共享频率与标尺系统，算术平均不构成系统误差消除。

## 声传播全文依据与模型映射

李轩、方锦江、单桂晔、高志华：《声波多次往返叠加对相位比较法测量声速的影响》，物理实验2018，38(4)：47–51。DOI：[10.19655/j.cnki.1005-4642.2018.04.011](https://doi.org/10.19655/j.cnki.1005-4642.2018.04.011)。五页全文独立核读，p48式1–5另经PDF渲染检查。p47引言给相邻驻波腹间距λ/2及同相重复2π对应λ；p48式1–3给多次往返路径，式4–5说明声压与位移及示波器通道对应。p49–50讨论有限衰减、多反射和近距离连续近同相造成判断困难。

本页standing模型是归一化接收端口的独立教学几何级数：H=(1−q)exp(−ikL)/(1−q exp(−2ikL))。q是每次完整往返的有效振幅保留率，默认0.7为教学输入，包含两次反射的合成效应；不是论文单面反射系数β=0.8。当前q固定、不另加距离衰减，归一化1−q是显示和端口耦合约定。该简化模型不能宣称定量再现论文的有限N、随传播距离衰减和近距多解图形。

phase模式用理想单程H=exp(−ikL+iφe)，忽略反射。声压与位移的π/2正交关系及换能器/电子延迟可归入固定φe；正负方向由选取的正弦参考约定，固定偏置不改变同相重复λ。论文20dB/m若用于振幅指数衰减，必须先换算αNp=αdB ln(10)/20，不能直接将dB数值代入exp。本首版不采用其转引衰减参数，也不以理想测量间距掩盖原装置近距系统误差。
