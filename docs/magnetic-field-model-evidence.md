# 磁场描绘：模型、参数与验证

## 模型依据

轴向场由每个圆线圈的Biot–Savart积分得到，叠加$B_z=\sum\mu_0NIR^2/[2(R^2+(x-c_j)^2)^{3/2}]$。单线圈原点在中心，双线圈原点在中点。d/R=1时双场中心二阶导数为零，但不是整个轴线均匀。

## 参数来源与适用范围

默认半径10.5cm、500匝、间距10.5cm沿原模型参数。原读数单位缺失；现图中的mT为独立模型计算，不赋予原观测mT身份。μ0采用经典近似值。

原报告CSV逐表保留在本页观测入口，来源路径和哈希沿原实验数据登记。模型教学值与原观测分别保存，不把原记录缺失值补成实测事实。

## 独立验证

270组用三维电流元叉乘的矢量线积分独立计算轴向场；包含正负位置、单/双线圈、三种间距。Node检查对称、线性电流缩放和亥姆霍兹中心二阶项。

检查结果和模型哈希见 [独立参考记录](simulation/magnetic-field-reference.json)。Node另检查解析算例、参数边界和所声明极限。

## 文献依据与范围

张敬芳、王明超、李泽朋、齐雪莲：《基于三维磁场自动化测量实验装置的亥姆霍兹线圈磁场分布研究》，大学物理实验，2026，39(2)：29–36。 [DOI](https://doi.org/10.14139/j.cnki.cn22-1228.2026.02.006)。全文已逐页核读，并查看关键公式原页。

p.30式(3)给出理想薄圆线圈轴向磁感应强度，式(4)将中心位于$\pm D/2$的两个同向线圈叠加，式(5)为中点值。项目将论文轴向$B$记作$B_z$，坐标$x$仍表示沿公共轴线的位移，$D$映射为$d$、每个线圈匝数为$N$：

$$B_z(x)=\sum_j\frac{\mu_0NIR^2}{2[R^2+(x-c_j)^2]^{3/2}},\qquad c_j=\pm d/2.$$

单线圈取$c_1=0$。以理想细线圈、同轴、同半径、同匝数、同向恒流及自由空间为条件；不含绕组横截面、磁性材料和探头尺寸平均。$B_z$是有方向的轴向分量，在当前正向电流场景为正；不是离轴三维场幅值。项目$\mu_0=4\pi\times10^{-7}\ \mathrm{H/m}$为经典近似，不称作现行SI的精确定义值。

由式(4)独立求导，中心二阶项正比于$d^2-R^2$，所以$d=R$时二阶项为零，并得$B_z(0)=(4/5)^{3/2}\mu_0NI/R$。这只说明中心附近的均匀性。文献p.31–34的主要测量配置为$D=2R$及$4R$，不能把其$D=2R$数据称为$d=R$的亥姆霍兹均匀场。当前软件范围$d/R=0.5\text{–}1.5$不直接复现文献这两组测量。

项目$N=500$、$R=10.5\ \mathrm{cm}$和默认间距沿原报告模型，$I=0.300\ \mathrm A$及开放控件按登记的教学场景计算。文献线圈平均直径112.5 mm、400匝、0.1–1 A和SS495A灵敏度属于另一装置。SS495A的$3\ \mathrm{mV/G}=30\ \mathrm{V/T}$是集成恒流传感器输出斜率，不能代入裸霍尔片的$K_H$单位$\mathrm{V/(A\,T)}$。原报告磁场读数单位缺失，模型的mT不用于补原记录单位或认定探头标定。

270组独立三维电流元叉乘积分核对轴向场，另检查对称性、电流线性以及中心曲率；参考采用独立数值线积分，非重新调用轴向闭式函数。论文pp.32–35测量偏差和特定仪器误差仅描述其装置，不作为本页误差容差。
