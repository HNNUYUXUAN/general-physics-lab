# 偏振光虚拟实验：模型、参数与验证依据

模型采用已取得并核读的偏振实验与Fresnel反射文献[1–2]；计算采用独立复矩阵与电磁边界方程检验。

## 模型与场景

输入Jones向量为 $(1,0)^T$。理想延迟片为旋转矩阵夹持的 $\mathrm{diag}(1,e^{i\delta})$，随后投影到检偏器方向 $(\cos\theta,\sin\theta)$。探测器电流为投影模平方乘独立满幅响应A，加恒定背景B。无波片时退化为 $I=A\cos^2\theta+B$；四分之一波片快轴45°时成为圆偏振，任意检偏器方向均为A/2+B。页面电场轨迹直接由Jones复振幅计算。

空气至非吸收各向同性玻璃的反射使用Snell与Fresnel关系，p偏振在 $\alpha_B=\arctan n$ 时反射率为零。n表示相对空气的折射率，忽略色散、吸收、表面粗糙及多界面干涉。

## 参数来源与范围

默认A=1.20mA、B=0.020mA、n=1.50、波片快轴45°是独立教学设定，不从原报告拟合反推。开放A=0.1–2mA、B=0–0.1mA、n=1.2–1.8、波片轴0–90°、检偏器角0–180°、入射角0–85°。波片状态只取未插入δ=0与理想四分之一波片δ=π/2。n没有具体玻璃牌号或波长身份，故不能解释为实际材料色散或标定值。

## 原报告与记录身份

原报告5次布儒斯特角及10组检偏器角/光电流单独保存在observations中。角度由度分转换，不先修约；马吕斯拟合使用原观测独立重算A与B。原报告未有波片后偏振椭圆的定量记录，虚拟轨迹不充当实测重建。

`manual-angle`是用户选择角度保存的操作读数，`ideal-model`是按10°间隔生成的模型扫描；反射与透射分别标记kind。马吕斯拟合仅接受未插波片、同一参数且同一来源的透射记录。三种记录身份不混用，保留模型参数、单位、版本、时间及原始读数。原角度重复性不包含零点、仪器与玻璃表面误差。

## 独立验证

浏览器模型按展开的实虚部计算Jones向量；独立Python使用NumPy复矩阵乘法，覆盖3响应幅度×4波片轴角×2波片状态的24场景、144方向投影。反射另覆盖3折射率×4入射角的12场景；s反射从边界方程线性系统求解，p反射用独立三角形式核对。原记录马吕斯拟合由SciPy linregress对照。

Node测试覆盖无波片极限、圆偏振、波片轴对准、Jones范数守恒、布儒斯特零点、法向反射、已知参数拟合和非法域。公开验证JSON保存源数据及代码哈希、独立方法、运行环境与未修约误差。

```text
node --test tests/polarization-model.test.mjs
python scripts/validate_polarization_simulation.py --repo-root . --output-root .
```

需全文核读的依据包括：Jones延迟片与投影、Fresnel反射与布儒斯特条件、马吕斯测量背景及波片状态观察；资料定位完成前不标记为已核读。
