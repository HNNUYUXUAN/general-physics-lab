# 单臂电桥：模型、参数与验证

## 模型依据

双支路分压开路检测电压为$V_{oc}=E/[M+1]-ER_s/(R_x+R_s)$，检测支路戴维南电阻为$(R_a\parallel R_b)+(R_x\parallel R_s)$。有限检流计电流由$V_{oc}/(R_{th}+R_G)$得到，平衡时$R_x=MR_s$。

## 参数来源与适用范围

所有绝对电源、未知臂、比率臂和检流计阻值是独立教学参数；原记录仅用于另批观测复查。比率M=0.1/1/10/100；教学待测10–1e5Ω，比较臂0.1–1e6Ω。

原报告CSV逐表保留在本页观测入口，来源路径和哈希沿原实验数据登记。模型教学值与原观测分别保存，不把原记录缺失值补成实测事实。

## 独立验证

108组比率、待测、±20%失衡与检测内阻情景，以独立两节点矩阵验证有限检流电流；平衡点反演与换向另有Node验证。

检查结果和模型哈希见 [独立参考记录](simulation/wheatstone-bridge-reference.json)。Node另检查解析算例、参数边界和所声明极限。

## 文献依据与核查

杨铁柱、赖晓磊、张志强、苏明、孟书生、潘峰：《基于LabVIEW的单臂、双臂电桥仿真实验系统开发》，大学物理，2017，36(6)：36–40，77。[DOI](https://doi.org/10.16854/j.cnki.1000-0712.2017.06.010)。已核读六页全文并检查p.37公式原排版。

p.37第2.1节式(1)支持单臂电桥的平衡比率；p.38第3.2节式(3)说明有限检流计内阻影响失衡读数。页面采用戴维南形式，独立两节点解验证其等价性。检流计内阻不用于调出平衡，实际调节比较臂。

文献的2%随机噪声及特定标准臂、检流计阻值未用作教学参数。全文哈希与定位见[参考文献JSON](wheatstone-bridge-references.json)、[BibTeX](wheatstone-bridge-references.bib)。
