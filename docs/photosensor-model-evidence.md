# 光敏传感器虚拟实验：器件、参数与验证依据

模型采用已取得并核读的Vishay BPW34官方数据表[1]，与原报告型号未明的记录分开，构成有明确波长、偏压与温度的独立器件教学场景。

## 器件依据与参数

Vishay数据表Document81521、Rev.2.1、23-Aug-2011，第2页Basic Characteristics给出25℃、λ950nm、反偏5V、辐照度1mW/cm²下反向光电流典型50μA，最低40μA。第3页图3描述同偏压和波长下光电流随辐照度近线性。软件采用通过典型点的比例关系 $I_{ph}=50E_e$，I以μA、E以mW/cm²计；软件域0–1mW/cm²属于该线性教学近似，不保证单个器件的校准准确度或全部辐照点的最低界。

第1页给出受光面积7.5mm²，软件等效面积0.075cm²，入射功率为 $P=E_eA$。默认50μA与75μW对应0.6667A/W的场景响应度，温度、波长和偏压身份固定，不外推到任意光谱、lux或太阳光。

数据表暗电流的典型2nA/最大30nA条件是反偏10V，未套入本5V模型。软件零点电流在±0.1μA内由用户作为独立零点/电路偏置校准变量设置，默认理想零点0不代表实测器件暗电流为零。

## 测量电路与有效工作点

理想运放虚地令二极管阳极0V、阴极+5V，线性区内维持反偏5V。反馈电阻1–200kΩ为独立教学设定，输出 $U=-R_f(I_{ph}+I_0)$。先关光保存暗输出，再开光测量，校正光电流为 $(U_{dark}-U)/R_f$。

软件声明±4.5V为理想测量电路线性范围，属于教学输出边界，不对应未给型号运放的保证规格。若理想输出超界，则虚地条件不再确认，实际反偏需要非线性电路另算；软件返回无效工作点，不以钳位后的电压冒充固定5V的实际器件响应。改变反馈电阻或零点后重新校准，自动扫描只保存线性点。

## 原报告身份与对照

原报告56组负载、端电压、10Ω取样电压及灯杆位置保留在独立观测JSON。取样电流按mV/10Ω换算成mA，按原图重算 $U_{pred}=I(R_n+10\Omega)$ 与记录之差；多条记录回路不一致，不能据此标定BPW34或拟合完整单二极管参数。灯杆位置未校准为辐照度；没有原器件短路、开路、效率和最大功率点数据。

操作零点/光照记录与自动模型扫描分身份保存，原始输出和零点与派生校正光电流分字段，保留固定器件条件、参数单位、模型版本与ISO记录时间。

## 独立验证

浏览器直接计算跨阻关系；Python独立构建虚地KCL与反馈电阻线性方程，用NumPy线性求解器求电流和输出，再做暗零点相减。覆盖3辐照度×3反馈电阻×3零点共27条件，其中6条件超界并核验invalid，不计为有效工作点。最大电压差1.78×10⁻¹⁵V，校正电流差3.56×10⁻¹⁵μA。

Node覆盖官方典型点、独立暗校正、越界拒绝、反馈与数据来源匹配以及波长偏压固定身份。验证JSON保留源与模型哈希、运行环境、容差和实际误差。
