# 碰撞规律：模型、参数与验证依据

## 模型

一维滑块系统，无外力冲量；滑块2碰前静止。碰撞作为瞬时事件，以恢复系数描述相对速度变化。

$$m_1u_1=m_1v_1+m_2v_2,\qquad v_2-v_1=eu_1.$$

$$v_1=\frac{m_1-em_2}{m_1+m_2}u_1,\quad v_2=\frac{(1+e)m_1}{m_1+m_2}u_1.$$

$$\Delta E=\frac12\frac{m_1m_2}{m_1+m_2}(1-e^2)u_1^2.$$

质量交换允许探索轻撞重及反弹；这些操作记录与原报告重撞轻观测分开。碰撞后可按挡光片长度和遮光时间反演速度，方向单独记录。静止滑块无过门时长，保存为null并按零速度处理。

## 观测身份与适用边界

原非弹性系列有5组入射与共速读数，SI单位换算后计算动量差和动能损失。弹性系列有5组碰后读数，滑块1两次速度沿原处理取均值；该组缺碰前速度，不能独立验证守恒或直接测恢复系数。没有原始轻撞重观测，不用质量交换的模型数据补齐原报告。

网页忽略空气阻力、导轨倾斜、接触持续时间与测量器触发延迟。手动改写过门时间是操作或假设测速偏移，自动值是理想模型。缺少仪器精度，不使用任意百分比阈值声明实际测量合格。

## 验证方法

独立Python以三未知量 $v_1,v_2,J$ 解两滑块冲量方程与恢复系数条件，覆盖质量、入射速度、恢复系数的81组边界与代表点，并对照约化质量动能损失公式。浏览器光电门反演保持方向，核对零速度无过门身份。Node另外检查等质量速度交换、粘合共速、轻撞重反弹、事件连续与不相互穿透。

数值记录及源文件哈希见 `docs/simulation/collisions-reference.json`。公式全文引用与页面视觉验收由集成队列接续。
