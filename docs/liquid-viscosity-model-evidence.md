# 落球黏度：模型、参数与验证依据

## 模型

浮力、重力及Stokes拖曳作用于均匀球体，管壁用一阶乘子 $W=1+2.4d/D$ 表示。以球体自身质量作惯性项：

$$m\dot v=(\rho_s-\rho_l)Vg-3\pi\eta dWv,\quad v(0)=0.$$

$$v_\infty=(\rho_s-\rho_l)gd^2/(18\eta W),\quad\tau=\rho_s d^2/(18\eta W),\quad x=v_\infty[t-\tau(1-e^{-t/\tau})].$$

数值二分反解两标线到达时刻；反演黏度用收尾近似 $\eta_{app}=(\rho_s-\rho_l)gd^2\Delta t/(18sW)$。从释放点开始计时会包括短暂加速阶段，导致正偏差。

## 观测与验证

原主报告六次累计时间31.28–189.60s单独回归累计斜率；另两组照片不拼接。源累计读数须代表同一测量区间累计下落耗时，投放间隔缺记录。原预算只含直径和计时指定分量，不完整量化密度、温度、管径、区间长度与模型误差。

独立Python用Radau积分浮重力和壁修正线性拖曳的力平衡，触发两标线位置事件，比较区间时长、到达时刻及0/1/3/5τ速度位移。Node另验终速受力平衡、瞬态ODE、壁效应、加速段偏差及适用域拒绝。结果见 `docs/simulation/liquid-viscosity-reference.json`。
