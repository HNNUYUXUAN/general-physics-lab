# 刚体转动惯量：模型、参数与验证依据

## 动力学及测量关系

无滑动轻绳、理想滑轮和相同恒摩擦力矩，正转阶段满足

$$J\beta_f=-\tau,\quad J\beta_a=Tr-\tau,\quad mg-T=ma,\quad a=r\beta_a.$$

联立消去张力与摩擦得到

$$J=\frac{mr(g-r\beta_a)}{\beta_a-\beta_f}.$$

八次半圈信号从同一初始状态开始，$k\pi=\omega_0t_k+\beta t_k^2/2$。用第1/5、2/6、3/7、4/8信号逐差消去初速。自由减速只开放能完成八次信号的正转阶段；模型不将停止后的恒摩擦外推为反转。

## 参数与适用范围

圆环0.436kg、内外半径0.105/0.12m，单柱0.166kg/半径0.015m，默认偏轴0.1m及塔轮0.025m来自原报告。平台惯量0.0056kg·m²、悬挂0.05kg、摩擦0.0005N·m、初速5rad/s是独立教学输入。软件域为平台0.003–0.008kg·m²、悬挂20–100g、塔轮15–30mm、摩擦0.2–1mN·m、初速5–10rad/s、偏轴0–150mm；均匀刚体几何，忽略轴承速率依赖与绳弹性。

$$J_{ring}=\tfrac12m(R_o^2+R_i^2),\quad J_{cyl}(d)=\tfrac12ma^2+md^2.$$

## 独立验证

Python以径向质量积分计算几何惯量，以三元约束力/力矩方程解加速度，再用DOP853积分角位移与速度并通过根事件计算八次遮光时刻。54组装载/参数算例对照浏览器模型，惯量和角加速度绝对容差1e-10、时间1e-9s。Node验逐差反演、配对惯量、平行轴、恒挂质量变化和非法时刻。验证记录见 `docs/simulation/moment-of-inertia-reference.json`。

## 文献定位

陈国华、程敏熙《智能手机磁传感器在落体法测量刚体转动惯量中的应用》，大学物理实验2020,33(6):55–57+71，DOI [10.14139/j.cnki.cn22-1228.2020.06.015](https://doi.org/10.14139/j.cnki.cn22-1228.2020.06.015)。已核读全部4页，其中第71页为本篇英文摘要与另一篇文章续页；已实际检查p55–57公式、装置及数据表。

p55§1.1式1、2、4分别给出定轴转动定理、$mg-T=ma$和$Tr-\tau=J\beta$。项目保留悬挂物的平动惯性，联立无滑动约束$a=r\beta$得$(J+mr^2)\beta=mgr-\tau$。论文式3、5另采用$g\gg a$从而$T\approx mg$；当前开放域并不统一满足忽略$a$的精度条件，因此不采用该近似，也不从其线性质量回归移植平台参数。

p56§1.2以每圈平均角速度对应该圈中间时刻。项目将该恒角加速度关系用于原报告的半圈光电信号，八次时刻从同一初始状态产生。令$u_k=k\pi/t_k$，由$u_k=\omega_0+\beta t_k/2$，独立得到配对逐差式$\beta_k=2(u_{k+4}-u_k)/(t_{k+4}-t_k)$。自由与驱动阶段同一恒摩擦的配对消元式、以及无滑动/忽略绳质量和滑轮惯量，是本项目明确的教学模型；论文使用磁传感器每圈信号，并未提供本项目八次半圈原始计时。

几何惯量由$J=\int r_\perp^2\,dm$独立积分：均匀圆环给出$m(R_o^2+R_i^2)/2$，均匀圆柱自轴给出$ma^2/2$；偏轴展开并用质心一阶矩为零得$J(d)=J(0)+md^2$。参考验证另用径向数值积分，不把用于设定教学默认值的原报告结果充作独立实测真值。

## 来源公式核查记录

- p56式8印刷分母为$T_2/2-T_1/2$。连续两圈的中间时刻分别为$t_0+T_1/2$与$t_0+T_1+T_2/2$，差为$(T_1+T_2)/2$；正确关系应为$\beta=2(\omega_2-\omega_1)/(T_1+T_2)$。p57表1第一项用$T_1=3.16\,\mathrm{s},T_2=2.40\,\mathrm{s}$和$\omega_1=1.988,\omega_2=2.618\,\mathrm{rad/s}$得$0.2266\,\mathrm{rad/s^2}$，与其列出的0.227一致，支持加号校正。此算例仅核查来源公式，未并入原观测。
- p57式9把负导数直接写入标准不确定度。对$I=gR/k$，标准不确定度贡献应取$|\partial I/\partial k|u(k)$；导数负号表示方向，不表示负不确定度。项目不移植其回归不确定度。
- 论文塔轮半径10mm、磁铁质量、悬挂砝码系列及结果属于另一装置，未替换本实验原报告的25mm塔轮、几何质量和源派生量，也不引用其教学效果为项目验证结论。
