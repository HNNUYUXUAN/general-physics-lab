# 多普勒验证：模型、参数与验证

## 模型及方向

声源固定于静止均匀空气，接收器沿声轴匀速运动。接近速度为正。声速温度近似沿原报告取

$$c=331.45\sqrt{1+\vartheta/273.15}\ \mathrm{m/s},\qquad f=f_0(1+v/c).$$

声源与接收器初始间距为 $d$，第 $n$ 个波前在 $n/f_0$ 发射，随后以声速运动。与接收器轨迹相交满足

$$c(t_n-n/f_0)=d-vt_n,\qquad t_n=\frac{d+cn/f_0}{c+v},\qquad \Delta t=\frac{c}{f_0(c+v)}.$$

波前间隔的倒数独立生成记录，用于与直接多普勒公式比较。数据身份保留为不同来源。温度模型是干燥空气近似，不含湿度、气压、组成及温度梯度修正。

## 独立验证

Python 用 Brent 根求解器分别求每个球面波前与接收器轨迹的交点，通过相邻到达间隔反算频率；不把浏览器多普勒公式作为参考。三种温度、三种声源频率、七种正负速度，共63组，每组前六个波前。

到达时刻绝对误差容差 $10^{-12}\ \mathrm s$，频率相对误差容差 $10^{-10}$。Node 另验静止极限、正负速度频移对称、距离对间隔的不变性、温度趋势和已知线性算例。参见 [独立参考记录](simulation/doppler-verification-reference.json)。

## 文献核读与显示范围

固定声源运动接收器理论已由下列全文核读支持。声速温度式标注原报告近似，精密环境修正超出本情景。

装置灰线按真实模型波长绘制，普通屏幕刷新不能逐周期显示40 kHz超声；波前位置图用于理解空间间隔，精确到达间隔由数值计算与时序图给出。当前模型没有引入反射、干涉、频率计量误差或空气流动。

## 已核读文献

文献 [1] p.91式(1)给出声波多普勒一般关系，p.92式(2)专门讨论固定声源、运动接收器及频率—速度斜率反演。已核读五页全文并渲染公式所在页面。p.93§3.3出现40002 Hz示例，但其30 °C情景和观测不作为本项目23.1 °C数据或默认来源。§3.3.2声源运动分母与式(1)及后续倒数式存在符号冲突，本项目只采用经波前推导确认的固定声源关系。

空气声速温度近似仍标识为本项目原报告模型，本文并未作为331.45系数精密校准来源。
