# 牛顿第二定律：模型、参数与验证依据

## 模型与测量

滑块、配重、悬挂砝码组成恒定总质量 $M$ 的系统；从滑块转移质量到挂钩，改变驱动力而不改变惯性总质量。理想滑轮与轻绳，恒定等效反向力 $f$。

$$a=(m_0g-f)/M,\quad m_0=(M/g)a+f/g,\quad v_2^2-v_1^2=2aS.$$

有限挡光片跨门中心前后各 $d/2$，两端速度由 $v_\pm^2=v^2\pm ad$ 给出，过门时间为

$$\Delta t=2d/(\sqrt{v^2+ad}+\sqrt{v^2-ad}).$$

按 $d/\Delta t$ 求得平均速度，与门中心瞬时速度有差异。页面提供瞬时速度模型、有限宽光电门、操作过门读数三种来源，分别拟合。

## 适用条件与验证

忽略滑轮惯量、绳质量与伸长，反向力在门间恒定；开放域保证驱动力大于阻力、总质量大于悬挂质量且 $v_1^2>ad$。有限宽公式按理想遮光几何，没有计时触发延迟与采样量化。

独立Python使用DOP853积分 $\dot x=v,\dot v=(m_0g-f)/M$，以门2位置触发事件取得时刻和速度，再从挡光片前后边缘速度独立求遮光时间。覆盖总质量、悬挂质量、阻力、门距、初速和宽度96组边界及代表组合，另检查五力系列拟合恢复指定总质量和反向力。Node检查分体受力、功和动能、到门时刻、零加速遮光时间、窄片极限、宽度偏差二阶收敛以及不相容来源拒绝。

结果与模型和输入哈希见 `docs/simulation/newton-second-law-reference.json`。
