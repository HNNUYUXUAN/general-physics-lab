# 电阻伏安特性：模型、参数与验证

## 模型依据

电流表内接时电压表跨越待测电阻与电流表，$U/I=R_x+R_A$；外接时电流表测得待测电阻与电压表并联电流，$U/I=R_xR_V/(R_x+R_V)$。

## 参数来源与适用范围

所有电表内阻为独立理想教学设定，原报告缺少内阻。软件开放U=0.05–2V、Rx=10–1e6Ω、RA=0.1–100Ω、RV=1e4–1e8Ω。原二极管仅保留观测，最高点量程冲突未作拟合真值。

原报告CSV逐表保留在本页观测入口，来源路径和哈希沿原实验数据登记。模型教学值与原观测分别保存，不把原记录缺失值补成实测事实。

## 独立验证

162组电路用独立节点或并联支路矩阵求解；检查低/高阻两个接法的加载方向与已知反演。

检查结果和模型哈希见 [独立参考记录](simulation/resistor-iv-reference.json)。Node另检查解析算例、参数边界和所声明极限。

## 文献依据与范围

杨铁柱、周帅、潘峰：《基于LabVIEW的电表的改装与校准仿真实验系统开发》，大学物理实验，2021，34(5)：98–102。 [DOI](https://doi.org/10.14139/j.cnki.cn22-1228.2021.05.023)。全文已逐页核读，并查看关键公式的原页渲染。

p.99图3、式(3)描述串联电阻的总压降，可作为本项目内接支路$U=I(R_x+R_A)$的基础欧姆关系；其中本项目$R_A$的身份是电流表内阻，原文串联臂的身份是扩程电阻，两种装置用途分别标明。

p.99图5及p.100式(9)明确包含电压表输入电阻$R_v$与被测支路并联。将该文$R_g+R_s$整体映射为本项目$R_x$，相同端电压下总电流为$I=U/R_x+U/R_V$，从而外接比值为$U/I=R_xR_V/(R_x+R_V)$。本项目端电压是电压表实际端电压，未把文中的电源电压直接当作读数。两种接法均由独立节点矩阵核对162组情景。

论文支持串并联、有限电压表加载的物理结构，不是内外接伏安实验的专项仪器说明。项目$R_A,R_V,R_x$仍为独立教学参数；原报告二极管数据保持单列，当前模型只处理欧姆电阻。内接法专项依据见下节梅等2022；本条杨等文献用于有限输入电阻的电路推导，未作为原仪表校准来源。

全文哈希、用途和定位见[参考文献JSON](resistor-iv-references.json)、[BibTeX](resistor-iv-references.bib)。

## 专项全文对应

梅诗雨、刘瑞琪、吴超浩、赵颖：《伏安法测电阻实验中量程转换对测量精度的影响》，大学物理实验，2022，35(5)：121–124。 [DOI](https://doi.org/10.14139/j.cnki.cn22-1228.2022.05.027)。全文已核读并检查原页公式。

梅等p.122图1与式(1)–(2)直接描述内接法$U=(R+R_A)I$，其$R$对应$R_x$、$V_m/I_m$对应$R_A$、$U$是电压表跨越电流表与待测电阻的实际示值。因此$R_{\mathrm{内}}=U/I=R_x+R_A$。式(5)的$U'=U-IR_A$说明只有已知对应量程的内阻才可修正。本文允许人为设置固定$R_A$，记录按$R_x,R_A,R_V$及接法分组；原记录未测内阻，不代入论文26–30 mV、25/50/100 mA值。

外接法的有限电压表加载采用已核读杨等2021 p.99图5、p.100式(9)的并联拓扑：该文$R_g+R_s$整支路映射为$R_x$，$R_v$映射为$R_V$。在相同实测端电压$U$下节点连续性给出$I=U/R_x+U/R_V$，即$R_{\mathrm{外}}=R_xR_V/(R_x+R_V)$。梅文没有外接法的专项计算，此部分依据与内接依据分别标明；162组独立节点矩阵检查两种接法。

精确相对加载误差为$\varepsilon_{\mathrm{内}}=R_A/R_x$、$\varepsilon_{\mathrm{外}}=-R_x/(R_x+R_V)$。其绝对值相等的位置为$[R_A+\sqrt{R_A^2+4R_AR_V}]/2$，常见$\sqrt{R_AR_V}$是$R_A\ll R_V$条件下的近似。原报告两电阻的读数不用于反推本台FB321的准确度或未记录内阻。

核查记录：梅文p.122式(3)印刷的最小二乘斜率分母漏$n$，式(4)分子与样本数量记号也有问题；本项目使用独立标准线性代数，不沿用这些排印公式。式(5)下量程分段区间互相重叠，且p.123表2存在小于25 mA但选50 mA档的点，实际量程应由操作记录确定，不能仅靠$I$大小推定。式(6)前的$V_m/2$也未用于模型。论文两组斜率、约150 Ω元件和源SPS3203D不作为项目标定数据。

两篇核读全文与明确的串并联推导足以支持本页已声明的恒定正内阻、欧姆电阻、理想读数教学模型；原FB321制造商、内阻规格和准确度仍属另一层装置信息。二极管原记录保持独立，当前前向模型没有未经辨识的半导体参数。
