# 牛顿环虚拟实验：模型、参数与验证依据

模型依据采用已取得并核读的李小芳等《基于Python的牛顿环仿真实验平台》[1]。全文第67–68页公式(1)–(5)给出半波损失、接触及非接触空气膜强度；本项目将其归一化并保留空气折射率 $n=1$ 的教学场景。

## 物理问题与测量过程

实验以读数显微镜测量牛顿环的左右位置，使用暗环直径平方与环级的含截距拟合，以及隔级差两种方法估计平凸透镜的曲率半径。网页提供独立教学场景与原报告观测对照。

原报告配置的波长为 $589.3\ \mathrm{nm}$。原始六组读数来自 `experiments/course-04/newton-rings/data/rings.csv`，级次为 5、10、15、20、25、30。网页从这些读数重新相减计算直径。原报告五组空气劈尖读数作为另一测量批次呈现，并计算细丝厚度。

## 模型与推导

单色光近法向入射到平凸透镜和平板间的空气膜，两束反射光等振幅；一次反射引入半波损失。忽略吸收、多次反射、像差、谱宽和接触形变。空气折射率取 1。球面近轴膜厚为

$$t(r)=t_0+\frac{r^2}{2R}.$$

反射强度采用

$$\frac{I(r)}{I_{\max}}=\frac{1-\cos[4\pi t(r)/\lambda]}{2}=\sin^2\!\left(\frac{2\pi t(r)}{\lambda}\right).$$

暗环满足 $2t=m\lambda$，因此

$$r_m^2=R\lambda(m-2t_0/\lambda),\qquad D_m^2=4R\lambda m-8Rt_0.$$

使用含截距模型 $D_m^2=am+b$，得到 $R=a/(4\lambda)$、$t_0=-b/(8R)$。不强制过原点。对于固定间隙，隔 $p$ 级之差消除截距：

$$R=\frac{D_{m+p}^2-D_m^2}{4p\lambda}.$$

中心间隙大于零时，中心未必为暗点，图像中从中心向外的可见环序号不一定就是方程中的 $m$。界面级数指方程干涉序号。第一级在 $t_0/\lambda=0.5$ 时收缩为中心点，不能作为有限直径暗环记录。

空气劈尖满足小角度线性膜厚，原报告采用 $N$ 个条纹间隔的长度 $l_N$ 计算细丝直径：

$$h=\frac{N\lambda L}{2l_N}.$$

源报告对“20条纹”的端点计数未另作记录，本项目沿用其公式及 $N=20$ 的间隔约定。

## 参数来源与开放范围

|参数|默认值|范围|来源身份与解释|
|---|---:|---|---|
|曲率半径 $R$|800 mm|300–1500 mm|独立教学设定；与原报告拟合值分开|
|波长 $\lambda$|589.3 nm|400–700 nm|默认沿用原报告；其他值为单色光模型扫描|
|中心间隙 $t_0/\lambda$|0|0–0.5|教学模型控制量，无实测间隙输入|
|测微镜中心坐标|25 mm|界面固定|坐标原点约定，对直径与拟合半径无影响|
|测微线读数|25 mm|20–30 mm，步长0.001 mm|用户交互读数；步长为软件离散，不能当作真实仪器分度或不确定度|
|暗环级数 $m$|5|1–100整数|指定干涉序号，须确认暗环位于可视范围内|
|隔级差 $p$|10|1–99整数|默认沿用原报告|

全域光场显示横纵各 $-5$ 至 $5\ \mathrm{mm}$；最远角点 $r^2=50\ \mathrm{mm}^2$，最小半径 $R=300\ \mathrm{mm}$。使用有理化形式求精确球面弓高

$$s=R-\sqrt{R^2-r^2}=\frac{r^2}{R+\sqrt{R^2-r^2}},$$

与近轴弓高 $s_0=r^2/(2R)$ 比较，最大相对膜厚偏差为 $1.3891\times10^{-4}$。这项是膜厚几何误差界限，不能直接等同于干涉强度相对误差。图像有限分辨率下，高级次条纹会收细，连续模型读数用于数值验证。

自动操作的范围额外要求 $20\le x_{\rm left}<x_{\rm right}\le30\ \mathrm{mm}$。当前中心25mm，因此可读暗环半径不大于5mm；模型函数允许的高阶暗环不自动等同为当前显微镜视场中可测读数。超视场自动记录被拒绝，提示降低级次或改变参数。

## 数据身份与分析

|身份|含义|处理方式|
|---|---|---|
|`original-report`|源 DOCX 中的显微镜和劈尖读数|独立数据表，使用原波长，重新计算|
|`ideal-model`|连续模型暗环坐标的自动记录|保存完整参数，按当前同一条件单独拟合|
|`manual-micrometer`|用户移动测微线取得的左右读数|保存参数与原始读数，单独拟合|
|教学参数|控制理想装置的设定值|不冒充原报告观测或独立校准值|

同一级重复记录保留在记录表中；拟合及隔级差要求每级唯一，界面提示读者移除重复级次，避免隐式选点。更改参数后历史记录仍可导出，但不会混入当前条件拟合。

原数据拟合半径 $806.4915759618\ \mathrm{mm}$，隔10级差四组均值 $805.2032071950\ \mathrm{mm}$。隔级差共享部分观测，不能直接视为独立重复量。拟合标准误差只来自残差，未记录仪器、校准与波长误差，不能据此给出完整标准不确定度。

## 独立验证与可复现性

运行：

```text
node --test tests/newton-rings-model.test.mjs
python scripts/validate_newton_rings_simulation.py --repo-root . --output-root .
```

Node 测试覆盖边界、暗中心与亮中心、暗环与亮环条件、灰度对称性、坐标平移不变性、记录身份、截距与间隙反演、隔级差、重复级次、非法斜率及劈尖已知算例。

独立 Python 采用 SciPy 有界极小化求反射光强的相位极小，再转换为空间坐标，与浏览器解析暗环半径对照；以 SciPy `linregress` 对原始左右读数的直径平方拟合。计算覆盖 3 个曲率半径、3 个波长、4 个间隙的 36 组参数，共252条暗环。

验证输出包括模型和源数据 SHA-256、运行环境、独立方法、逐项容差及最大误差。初次运行的最大暗环坐标误差 $8.89\times10^{-16}\ \mathrm{mm}$，模型回归半径误差 $1.14\times10^{-12}\ \mathrm{mm}$，隔级差半径误差 $5.46\times10^{-12}\ \mathrm{mm}$。

图场采用2001×2001采样、单轴步长0.005 mm。最小 $R\lambda$ 条件下，单轴最大相位变化为2.618 rad，小于Nyquist上限 $\pi$；显示缩放不增加模型信息，精确暗环位置仍取连续模型。
