# 霍尔效应：模型、参数与验证

## 模型依据

均匀线性教学关系$V_H=K_HIB$。四极性原始电压在基底$s_Bs_I,1,s_I,s_B$上分解；顺序(+B,+I)、(−B,+I)、(−B,−I)、(+B,−I)。霍尔投影$(V_1-V_2+V_3-V_4)/4$，同奇偶性副项无法与霍尔分离。

## 参数来源与适用范围

默认K_H=100V/(A·T)、B=0.3T及偏置均为数学教学参数，不指称原样品材料或厂家规格。原记录缺少K_H、厚度及B标定，保留三个观测批次与其冲突，不合并测载流子浓度或绝对磁场。

原报告CSV逐表保留在本页观测入口，来源路径和哈希沿原实验数据登记。模型教学值与原观测分别保存，不把原记录缺失值补成实测事实。

## 独立验证

216组情景用NumPy线性方程反演四分量，检验方向和投影；Node验证零场极限、不同奇偶项的消除、同奇偶项残留及完整四次采样才允许反演。

检查结果和模型哈希见 [独立参考记录](simulation/hall-effect-reference.json)。Node另检查解析算例、参数边界和所声明极限。

## 文献依据与范围

陈浪、尹航、李楚涵、李春辉、吕梦雪、张宇飏、邢家林、何学敏：《基于LabVIEW的霍尔效应测量磁场仿真实验平台》，大学物理实验，2025，38(4)：115–124。 [DOI](https://doi.org/10.14139/j.cnki.cn22-1228.2025.04.019)。全文已逐页核读，并查看关键公式原页。

p.116式(1)–(3)支持线性霍尔关系$V_H=K_HIB$。$R_H$是材料霍尔系数，量纲$\mathrm{m^3/C}$；$K_H=R_H/h$是片厚相关灵敏度，量纲$\mathrm{V/(A\,T)}$。论文先以$h$定义厚度，式(2)换成$d$，这里统一视为同一片厚。论文以正的$e$书写电压大小，项目符号由换向顺序约定，不由这些幅值式反推载流子类型。

论文$\mathrm{mV/(mA\,T)}$与项目$\mathrm{V/(A\,T)}$数值相同，因此代码$K_H\,I_{\mathrm{mA}}\,B_{\mathrm T}$直接得到mV。例如教学默认$100\times3\times0.3=90\ \mathrm{mV}$。$K_H=100$、$B=0.3\ \mathrm T$及各偏置是独立教学参数，原报告3 mA仅保留记录身份。文献$K_H=190$、500匝、半径10 cm、励磁0.5 A及随机副效应属于作者仿真，未当作原仪器标定；该文0.06%是作者仿真对照结果，不是本项目精度。当前页面直接设置磁感应强度$B$，没有伪设$B=\beta I_M$的线圈校准常数，也不由缺失的片厚、$K_H$或$B$推算原样品载流子浓度。

p.116式(4)–(7)的电压符号与p.120实际操作顺序对应$(+B,+I),(-B,+I),(-B,-I),(+B,-I)$；式(6)行首印为$(+I,+I_M)$，与其电压符号和第3次实际换向步骤不符，应按$(-I,-I_M)$理解。项目直接使用完整的四极性符号表：

$$V(s_B,s_I)=s_Bs_I(V_H+V_{\mathrm{same}})+V_0+s_IV_I+s_BV_B,$$

$$\widehat V_H=\frac{V_1-V_2+V_3-V_4}{4}=V_H+V_{\mathrm{same}}.$$

按论文式(4)–(7)实际印刷符号，$U_O,U_N,U_R$均为$(+,+,-,-)$序列，合为电流奇分量$V_I$；这些式子没有独立给出磁场奇$(+,-,-,+)$分量。项目$V_B$与$V_0$是分别加入的磁场奇、共模教学基底，不直接命名为论文某种材料副效应；文献印刷的副效应符号与各微观机制的关系另行核查，当前投影仅按明确基底验证。爱廷豪森项$U_E$与霍尔同奇偶性，对应$V_{\mathrm{same}}$，四次换向无法将二者分离。论文式(8)采用绝对值平均，得到$|V_H+U_E|$；项目使用有符号投影，二者在总同奇偶项非负时相同。原文后称此副效应“没有影响”，但式(8)仍含它，不能据此判定其为零。

四个可调附加项表示奇偶基底上的电压，不是由温度、热导或材料参数预测的微观副效应强度；在同一组采样中保持它们不变。216组独立4×4线性方程求解验证投影与残留，不把由同一$K_H$前向生成的斜率当作外部灵敏度校准。论文p.117式(11)一项分母重复$(y-R\sin\theta)^2$，本项目未用其离轴积分或据此建立磁场模型。
