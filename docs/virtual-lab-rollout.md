# 系列虚拟实验建设顺序

单摆为已验收的首例，系列覆盖四门课程的45个实验。各实验围绕设置条件、操作观察、取得读数、记录分析与解释结果组织，使用独立物理模型和逐实验证据矩阵。

|组|实验|
|---|---|
|1|RLC谐振、牛顿环、弦振动|
|2|物质密度、碰撞、牛顿第二定律、多普勒验证、惯性秤、薄透镜、单缝衍射、偏振|
|3|制流分压、电阻伏安、单臂电桥、交流电桥、示波器、万用表、电表改装校准、双臂电桥|
|4|分光计、棱镜顶角、棱镜折射率、掠射法、透射光栅、光学测长、旋光、迈克尔逊干涉仪|
|5|多普勒应用、声速、转动惯量、波尔共振、静电场、磁场、霍尔效应|
|6|杨氏模量、表面张力、线膨胀、黏度、汽化热、热功当量、导热|
|7|光敏传感器、阿贝成像、全息照相|

公共理论按物理专题检索，各实验另行核读装置、修正项、参数与适用范围。两校数据库交叉检索后仍缺全文的条目使用读秀文献传递。公开书目包含稳定引用和正文定位，全文保存在本地归档。

原报告观测、文献或校准参数、模型记录、用户操作读数分别标明身份。原报告参数不足时使用有据的独立教学场景。每个实验核对模型方程、参数来源、适用范围与独立验证方法。

构建由仿真登记表驱动。执行 `python scripts/validate_simulations.py --experiment course-01/pendulum` 检查单项，`--all` 检查已实现项目。各次运行在独立目录保留日志、源哈希和数值对照。

数值验证与前端验收分别记录。前端检查涵盖默认与改变参数的状态、测量和记录、恢复导出、字体公式、题注及桌面与窄屏布局。通过验收的页面进入[虚拟实验目录](../simulations/README.md)。
