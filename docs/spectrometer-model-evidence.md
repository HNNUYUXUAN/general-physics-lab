# 分光计虚拟实验：模型、参数与验证依据

当前二维双游标测角的操作依据为徐崇《用掠入射法测量透明介质折射率的探讨》，大学物理实验2009，22(1)：9–13，DOI：[10.14139/j.cnki.cn22-1228.2009.01.005](https://doi.org/10.14139/j.cnki.cn22-1228.2009.01.005)，全文5页已核读并渲染p10–12数学/装置。真实分光计的机械调节范围参照刘文晶等《改进反射法测三棱镜顶角实验的思考》，大学物理实验2023，36(2)：77–80，DOI：[10.14139/j.cnki.cn22-1228.2023.02.017](https://doi.org/10.14139/j.cnki.cn22-1228.2023.02.017)，全文4页及p78–79关键装置页已核看。两文的具体液体/顶角装置与本页通用方向测角分开；当前证据同时包含原观测核对、显式教学扰动模型与独立复数圆周角差验证。

## 测量问题

望远镜转动到基准和目标方向，保存对置两游标读数，各自求有向圆周最短差，再取平均及绝对值。物理角差限定小于180°，恰好180°因方向不唯一而拒绝。

徐2009 p11第2节步骤(3)/(4)要求分别记录两个定位方位的两游标，式(8)用两个方位差的绝对值平均求角。本页沿用该读取程序；方向越过0°时独立用圆周最短差消除360°跳变，在同向差的范围内与文中绝对角差平均一致。该引用是通用测角程序依据，不迁用其液体样品、棱镜或数据。

为探索双游标作用，软件引入独立的一阶反号谐波读数模型：

$$v_1(\theta)=\theta+z+\varepsilon\cos(\theta+z),\quad v_2(\theta)=\theta+z+\pi-\varepsilon\cos(\theta+z).$$

相同方向的误差反号，两次读数的差再平均后精确消去该一阶项。此模型是教学扰动，不能充当实际分光计完整校准方程；高次分度、望远镜视准、平台水平和光线定位误差不在当前角度模型内。

两篇论文均未给上述具体反号谐波校准式；因此一阶消除仅是所声明等幅反号模型的独立代数结果。不是依据“对置”一词就推断任意真实误差均被抵消。刘2023 p77区分反射与自准直，p78第1节说明望远镜轴线/平面镜粗调及视场，p78–79第2节、图2说明实际棱镜放置与反射像。本页没有对应机械自由度，不将这些实际操作步骤认作已实现仿真。

## 参数与数据身份

教学默认偏向角43.25°、刻度零点10°、一阶偏心幅度5′。开放偏角10–80°、零点0–360°、幅度0–10′。望远镜旋转步长0.01°，游标显示至0.01′，这些软件数值分辨率不代表仪器分度。真实源报告误差限1′仅按其原定义用于原报告不确定度说明。

自动对准记录标为`ideal-model`，实际望远镜选择的基准/目标角读数标为`manual-telescope`。模型设定、所有四个原读数及估计角度一并保存/导出。源DOCX中的自准直、平台水平检验以及5组双游标偏向读数保留为`original-report`，不与虚拟记录混用。

## 独立验证

浏览器使用模360°和模180°实现圆周差；独立Python把方向变为单位复数，用商的相位取得方向差。覆盖3偏角×3零点×3偏心幅度的27场景，包括跨零刻度。原报告5组结果用独立复数方法重算，均值43.2616666667°、均值A类分量0.300′。

Node测试覆盖跨零、180°歧义、反号扰动消除、单游标误差、手动角度与理想目标区分和非法输入。验证记录保存代码/源输入哈希、环境及误差。
