# 直流双臂电桥：模型、参数与验证

## 模型依据

主电流路径Rx-r-Rs，副臂p+q并联跨r，有效连接阻抗$r(p+q)/(r+p+q)$。主分点$V_1=E/(1+P/Q)$，副分点$V_2=I[R_s+rq/(r+p+q)]$。由V1=V2独立推得$R_x=(P/Q)R_s+r[(P/Q)q-p]/(r+p+q)$。

## 参数来源与适用范围

桥端电压、低阻、连接电阻、比率失配均为独立教学值；绝对主/副比率阻值定义明确。主副比率匹配时接触修正项消失；失配过大可能要求负标准臂，页面拒绝定位并提示调整。

原报告CSV逐表保留在本页观测入口，来源路径和哈希沿原实验数据登记。模型教学值与原观测分别保存，不把原记录缺失值补成实测事实。

## 独立验证

243组四节点物理电路独立求解，包括零接触短路、±10%副比率失配和比率0.1/1/10；Node检查匹配消除项、接触零极限、失配修正方向及平衡反演。

检查结果和模型哈希见 [独立参考记录](simulation/kelvin-bridge-reference.json)。Node另检查解析算例、参数边界和所声明极限。

## 文献依据与核查

杨铁柱、赖晓磊、张志强、苏明、孟书生、潘峰：《基于LabVIEW的单臂、双臂电桥仿真实验系统开发》，大学物理，2017，36(6)：36–40，77。[DOI](https://doi.org/10.16854/j.cnki.1000-0712.2017.06.010)。已核读六页全文并检查p.37公式原排版。

p.37第2.2节三条Kirchhoff方程支持双桥电流路径。对应本项目符号$M=R_3/R_1$、$q=R_2$、$p=R_3^{\prime}$，由方程消元得到

$$R_x=MR_N+\frac{r(Mq-p)}{r+q+p}.$$

文中紧接三条方程的无编号修正式，分母印为$R_3+R_3^{\prime}+r$；独立重推应为$R_2+R_3^{\prime}+r$，与本项目四节点物理电路243组参考计算一致。保留这一核查记录，计算使用上式。平衡调节标准臂；检流计内阻只影响离开平衡时的灵敏度。

文献的2%随机噪声及特定标准臂、检流计阻值未用作教学参数。全文哈希与定位见[参考文献JSON](kelvin-bridge-references.json)、[BibTeX](kelvin-bridge-references.bib)。
