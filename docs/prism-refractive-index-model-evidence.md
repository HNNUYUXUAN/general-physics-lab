# 棱镜折射率虚拟实验：模型、参数与验证依据

核心两面折射与最小偏向模型的全文依据为：谭锦博、吴秀梅，《三种测量三棱镜折射率方法的讨论》，物理与工程2024，34(3)：172–177。全文6页已核读并逐页渲染检查，重点为印刷p174–175公式(8)–(19)及图5–6。PDF及数据库题录未给出DOI，按已核实完整题录引用。

## 光路与测量

均匀非吸收棱镜的两面折射按 $\sin i=n\sin r_1$、$r_1+r_2=A$、$n\sin r_2=\sin e$ 计算，偏向角为 $\delta=i+e-A$。对称光路满足 $i=e$、$r_1=r_2=A/2$，因而 $i_{\min}=\arcsin[n\sin(A/2)]$ 与 $n=\sin[(A+\delta_{\min})/2]/\sin(A/2)$。

论文p174式(8)–(9)给两面Snell定律，p175式(10)–(11)给内部角和偏向角几何，式(12)–(17)由偏向角导数得到对称极小，式(18)–(19)给反演。论文的$n=n_2/n_1$为相对折射率；本页面外部空气取1，设定n即此相对量。p175第2.3节操作用望远镜跟踪谱线转向点寻找最小偏向，支持页面的入射角搜索及对称位置对照。

页面允许逐步改变入射角，观察出射方向，转动望远镜保存双游标读数；对称光路按钮可验证找到的最小值。未到最小值时，按最小偏向公式求出的“表观折射率”会偏高，记录明确标记`at_minimum`，不将其自动校准为设定n。第二面全反射时不生成可读出射线。

## 参数与身份

默认顶角60°沿原报告配置，n=1.50是独立教学设定，默认入射角由对称条件计算。教学域A=40–70°、n=1.3–1.7、i=0–85°；该域包含可出射条件，也允许观察全反射失败状态。未含色散、吸收、反射多光路和棱镜表面误差。两游标反号的一阶谐波扰动、零点和圆周差与分光计角度组件相同，软件数值精度不代表仪器分度。

该域最大$n\sin(A/2)=1.7\sin35^\circ<1$，故每组A/n都有可达到的对称透射位置；并不意味每个入射角都能从第二面出射。论文采用钠光、约60°棱镜和参考n=1.6500，其数值与测量结果不替换本页n=1.50教学场景。p173所述FGY分光计30角秒是论文仪器分度，不用它改写原报告1角分或软件0.01角分显示约定。

模型自动对准记录和用户望远镜读数分身份保存；原报告5组最小偏向读数独立重算，顶角60°及原角不确定度信息沿用源配置。不能把拟合得到n再当作独立材料标定输入。

## 核查与证据边界

论文p173的顶角方法为两个面分别自准直、使用补角关系$A=180^\circ-\varphi$。本项目独立的顶角实验用同束双反射夹角$2A$，不将两种方位定义混用。图2的$\varphi$按所选法线方向定义，表1望远镜最短角差不能不经法线支向判断就等同于$\varphi$；本页面不挪用该表作为原顶角观测。

p175式(20)将p偏振反射幅度写成正弦比，无法由该式得到所述Brewster消光；本页面不使用式(20)，两面Snell与最小偏向的式(8)–(19)另由独立求根/极小值算法确认。论文三方法准确性排序是其特定批次结论，不作普遍排名或软件误差保证。

模型两面Snell和最小偏向的关键全文已核读。对置游标误差消除及原报告不确定度条件保留原DOCX/独立几何身份，仪器校准和完整误差传播的教材定位另行维护。
