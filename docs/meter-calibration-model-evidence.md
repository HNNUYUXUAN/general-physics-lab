# 电表改装与校准：模型、参数与验证

## 模型依据

电流扩程用并联分流，表头电流由电阻分流决定；电压扩程用串联电阻。设计$R_{sh}=R_g/(I_m/I_g-1)$，$R_s=U_m/I_g-R_g$。误差采用改装示值减标准输入，上行下行分别保留。

## 参数来源与适用范围

Ig=1mA来自原设计，Rg=30Ω由源7.5Ω分流、五倍扩程反推，非独立实测。所有trim偏离、标准理想输入与无迟滞是教学模型。欧姆设计比较原1000Ω及改进1100Ω，电位器470Ω范围独立核对。

原报告CSV逐表保留在本页观测入口，来源路径和哈希沿原实验数据登记。模型教学值与原观测分别保存，不把原记录缺失值补成实测事实。

## 独立验证

24组改装回路用节点/串联矩阵验证。Node检查5mA分流7.5Ω、1.5V倍压1470Ω、trim误差方向和上/下行理想一致性。

检查结果和模型哈希见 [独立参考记录](simulation/meter-calibration-reference.json)。Node另检查解析算例、参数边界和所声明极限。

## 文献依据与范围

杨铁柱、周帅、潘峰：《基于LabVIEW的电表的改装与校准仿真实验系统开发》，大学物理实验，2021，34(5)：98–102。 [DOI](https://doi.org/10.14139/j.cnki.cn22-1228.2021.05.023)。全文已逐页核读，并查看关键公式的原页渲染。

p.99式(1)–(2)的并联分流给出$R_p=I_gR_g/(I_m-I_g)$，对应本项目$R_{\mathrm{sh}}$。式(3)–(4)给出串联扩程$R_s=U_m/I_g-R_g$，对应本项目$R_{\mathrm{series}}$。$I_g,R_g,I_m,U_m$与项目同名物理量逐一对应；原设计的1 mA、30 Ω、5 mA、1.5 V单独保留来源身份，未换成论文装置参数。

校准输入定义为已经施加到改装表上的理想标准电流或端电压，分流/串联网络据此求表头电流。论文图4–5还包含有限内阻的标准表和供电支路；这些部件会影响由电源电压到标准输入的关系，本项目不把理想标准输入误称为论文的电源设定值。24组独立节点/串联参考计算核对当前模型。

采用p.99式(5)前的代数约定$\Delta=\text{示值}-\text{标准}$，页面称为示值误差；加到示值上的修正量为$-\Delta$。满量程相对示值误差与准确度等级分开，式(5)中表头分量$a_0$没有项目依据，不能仅凭理想回路的零误差认定仪表等级。当前模型线性、无迟滞，上下行记录操作顺序。

论文p.99–100的1 Ω源内阻、100 Ω标准电流表内阻、100 Ω表头、11 MΩ电压表及2%随机读数误差属于作者仿真场景，均未用作项目参数或不确定度。项目欧姆档1100/1000 Ω、470 Ω调零设计继续按原报告单独分析；该文不提供欧姆档的专项依据。
