# 物质密度：模型、参数与验证依据

## 模型与操作

理想天平比较两侧视质量，浮力由阿基米德原理给出。固体在空气中质量 $m=\rho_sV_s$；浸没体积分数 $q$ 时 $m_s=m-q\rho_wV_s$。完整浸没时

$$\rho_s=\rho_w m/(m-m_s),\qquad V_s=(m-m_s)/\rho_w.$$

比重瓶空瓶、纯水和待测液体总质量分别为 $m_0,m_w,m_b$，相同温度、相同装液条件的瓶容积为 $V_p$，故

$$m_w=m_0+\rho_wV_p,\quad m_b=m_0+\rho_bV_p,\quad\rho_b=\rho_w(m_b-m_0)/(m_w-m_0).$$

手动操作通过调整右盘砝码寻找平衡。自动配平保存理想质量。天平横梁倾斜是视质量差的单调显示映射，未模拟具体仪器力矩与角响应。部分浸没记录保留身份，但不用于完整浸没公式。

## 适用范围

忽略空气浮力、吊丝排水、气泡、液体表面张力和温度漂移。固体完全浸没且不碰壁；比重瓶装液达到相同容积。不同物体教学参数、不同数据来源分别反演，保留每种称量的最后一次读数；原始记录全量导出。

## 验证

Node验证解析反演、部分浸没极限、质量缩放、共享空瓶质量平移抵消、灵敏系数及身份分组。Python在54组代表和边界条件下，固体以力平衡方程独立求根、液体以容积线性方程求解，并用中心差分检验各原始质量和水密度的偏导数。原观测另按五组质量均值复算，不将源表平均值计为第四次测量。

验证文件记录源输入、模型与脚本哈希，结果见 `docs/simulation/density-reference.json`。前端检查由集成队列执行。
