# 单缝衍射虚拟实验：模型、参数与验证依据

模型采用已下载并核读的安盼龙等《夫琅禾费衍射光强分布研究》[1]，第4页第1.1–1.2节区分透镜焦面与自由空间远场，第5页第2.1节公式(1)给出单缝sinc平方强度。

## 模型

单色标量平面波均匀照明宽度 $a$ 的单缝，采用夫琅禾费模型。归一化复振幅是孔径傅里叶积分：

$$A(\theta)=\frac1a\int_{-a/2}^{a/2}e^{i2\pi u\sin\theta/\lambda}\,\mathrm du,\qquad I/I_0=|A|^2=(\sin\beta/\beta)^2,\quad\beta=\pi a\sin\theta/\lambda.$$

屏面角度用 $\sin\theta=x/\sqrt{L^2+x^2}$；中心取连续极限1。暗纹满足 $a\sin\theta_k=k\lambda$。软件用精确屏面角度几何，原观测同时展示源报告近轴关系 $a=k\lambda L/|x_k|$，便于核对修正量。

## 参数

波长632.8 nm、屏距800 mm来自原报告配置；缝宽0.200 mm是独立教学设定，并非用原拟合值进行独立验证。软件范围为缝宽0.05–0.20 mm、屏距800–2000 mm、波长500–700 nm；按全缝宽定义的Fresnel数 $a^2/(\lambda L)\le0.1$。文献第4页第1.2节给出远场条件 $R,Z\gg a^2/(4\lambda)$，本项目将软件域限制为 $L\ge40a^2/(4\lambda)$，并采用平面波输入；0.1是软件教学筛选约定，不声明统一的近场误差百分比。图中不包含近场二次相位、探测器有限孔径、背景、缝厚、偏振与实际光源谱宽。

## 记录与原始观测

`ideal-model` 是解析暗纹坐标；`manual-probe` 包含用户采样强度及选定级次的暗纹位置，两类记录的 `kind` 分别为 `scan` 或 `dark`。仅相同参数、相同来源的至少三个唯一暗纹级次进入 $\sin\theta_k=Ak+B$ 拟合；由 $a=\lambda/A$ 求缝宽。扫描强度不作为暗纹读数。

原报告17个归一化光强点及4个暗纹读数单独呈现，输入文件保留SHA-256。源扫描缺原始电流和暗电流，无法重新验证扣背景；不同级次共享系统误差，跨级离散不代表完整标准不确定度。

## 验证

Node测试验证中心极限、正负对称、暗纹条件、参数边界、距离尺度、同参数分组和反演。独立Python采用SciPy对归一化复孔径积分的实部和虚部分别求积，再求模平方，与浏览器sinc²实现比较。覆盖3个缝宽×3个屏距×3个波长，共27参数组、243扫描点，另对108个暗纹做积分零点检验。

曲线步长0.025 mm；软件全域最小近轴暗纹间距2 mm，至少80采样点/间距。输入和代码哈希、环境、容差及实际最大误差保存在独立验证JSON。

## 文献与采用定位

[1] 安盼龙，赵瑞娟，郑永秋. 夫琅禾费衍射光强分布研究. 大学物理实验，2021，34(5)：4–7. [DOI:10.14139/j.cnki.cn22-1228.2021.05.002](https://doi.org/10.14139/j.cnki.cn22-1228.2021.05.002)。

|位置|依据|采用方式|
|---|---|---|
|第4页，第1.1节及图1|透镜焦面接受夫琅禾费图样|区分焦面实现与本页远屏场景|
|第4页，第1.2节及图2|平面波照明与 $R,Z\gg a^2/(4\lambda)$|限制软件远场域，保留模型近似身份|
|第5页，第2.1节，公式(1)|sinc平方强度及β定义|直接归一化为中心强度1，β=0用连续极限|
|第5页，第2.1节，公式(1)后第(2)点|非零级暗纹及小角度关系|暗纹用精确sin几何，原近轴数据另列|
|第6页实验场景|650nm、0.2mm等文献参数|作为该论文场景，不替换本项目632.8nm原记录|

原文第5页公式(1)后第(1)点把中央极大条件排印为与非零暗纹冲突的表达式；本项目由sinc连续极限核验中央极大为β=0，第(2)点非零整数暗纹保持相应意义。右栏双缝公式(2)也有排印问题，本实验未采用该式。
