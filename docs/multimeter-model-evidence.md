# 万用电表：模型、参数与验证

## 模型依据

直流电压输入阻抗与源内阻分压。数字表量程分2000计数；指针表用20kΩ/V灵敏度。串联欧姆电路基准内阻$R_b=1500k$、基准满偏电流$I_g=1.5/R_b$，实际内阻$zR_b$，$I/I_g=(E_b/1.5)/(z+R_x/R_b)$。

## 参数来源与适用范围

所有表型内阻、计数与灵敏度均为独立理想教学值。基准欧姆刻度按Rb制作；更换电池并短接调零使z=Eb/1.5，零点恢复但实际中点随z改变，页面保留这一影响，不将更新电池后的基准刻度称为精确标定。

原报告CSV逐表保留在本页观测入口，来源路径和哈希沿原实验数据登记。模型教学值与原观测分别保存，不把原记录缺失值补成实测事实。

## 独立验证

81组独立电压节点和欧姆回路矩阵检查加载、读数与刻度；另测短接、等内阻中点、量程溢出和电池影响。

检查结果和模型哈希见 [独立参考记录](simulation/multimeter-reference.json)。Node另检查解析算例、参数边界和所声明极限。

## 文献依据与范围

杨铁柱、周帅、潘峰：《基于LabVIEW的电表的改装与校准仿真实验系统开发》，大学物理实验，2021，34(5)：98–102。 [DOI](https://doi.org/10.14139/j.cnki.cn22-1228.2021.05.023)。全文已逐页核读，并查看关键公式的原页渲染。

p.99图5及p.100式(9)包含有限输入电阻$R_v$对供电支路的加载。移除改装表支路（令$R_g+R_s\to\infty$）后得到

$$U_{\mathrm{read}}=E\frac{R_v}{R_1+r+R_v},$$

与本项目电压档关系相同，其中$R_1+r$映射为源内阻$R_{\mathrm{source}}$、$R_v$映射为本页所选表型输入电阻。论文11 MΩ是作者的另一套仿真设定；项目10 MΩ、2000计数及20 kΩ/V均维持独立教学身份。

该文没有给出万用表的串联欧姆档、短接调零、电池更换后的刻度变化或项目表型规格。欧姆档目前依据原报告电路和明确的串联欧姆推导，并由81组独立节点/回路参考核验。本条杨等文献覆盖电压档有限内阻加载；欧姆操作的专项依据与独立教学回路推导见下节。

全文哈希、用途和定位见[参考文献JSON](multimeter-references.json)、[BibTeX](multimeter-references.bib)。

## 仪器操作依据与教学回路映射

安福全：《MF47型万用表的原理及使用》，职业，2015(30)：146。全文已在原页渲染上完整核读。

安福全p.146第1节介绍磁电式测量机构与直流电压串联电阻支路，说明测阻使用内部电池；第2.2节支持测阻前短接调零、换欧姆档后重新调零、刻度读数乘倍率，以及尽量在刻度中段读数。文中指出所述表的内部1.5 V电池可影响调零。这些内容是本页操作流程与仪器类别的依据，不提供该台MF47的完整电路图或定量灵敏度规格。

本页将欧姆档明确建模为**简化串联教学回路**。原报告给出$E_b=I(R_g+R+R_0+R_x)$，把内部支路合成$R_{\mathrm{int}}$后，由串联欧姆关系得到

$$I=\frac{E_b}{R_{\mathrm{int}}+R_x}.$$

杨等2021 p.100式(6)提供独立串联支路关系；安文不含这个数学式，不能把上述推导标作原文公式。令教学基准$E_0=1.5\ \mathrm V$、$R_b=1500k\ \Omega$、$I_g=E_0/R_b$，以及$R_{\mathrm{int}}=zR_b$，则

$$\frac I{I_g}=\frac{E_b/E_0}{z+R_x/R_b},\qquad R_{\mathrm{示}}=R_b\left(\frac{I_g}I-1\right).$$

$k=1,10,100$是所选欧姆倍率；$R_b,I_g$是该教学等效在各档的归一化基准，不反推真实表头灵敏度或MF47分流网络。短接调满偏使$z=E_b/E_0$，而绘制的基准欧姆刻度仍使用$R_b$。电池变化和调零后，等效中值电阻可以变化，因此原基准刻度会出现偏差；图中该效应是单回路条件下的计算结果，未声称复现MF47全部实际调零支路。

直流电压加载仍采用杨等p.99图5、p.100式(9)的有限输入电阻拓扑，去除另一并联被测支路，得$U=E_sR_V/(R_s+R_V)$。指针教学输入阻抗定义为$R_V=S_VU_{\mathrm{FS}}$，$S_V=20\ \mathrm{k}\Omega/\mathrm V$为独立灵敏度设定；安文没有此值。原报告仅记“MF47类”和未注明型号的DMM，本页2/20/200 V教学档与原指针量程250/10/2.5/1 V分别保留身份。

数字通道是独立的**理想量化读数模型**：输入阻抗设为10 MΩ，分度$q=U_{\mathrm{range}}/2000$，在加载后的端电压上以$q$舍入。2000为教学分度定义，不指称某款1999最大显示仪表；当前量程阈值和边界显示按软件定义，不由该篇MF47文章提供。未增加真实DMM型号、量程准确度或完整ADC动态特性。

81组独立回路参考核对加载、串联欧姆、倍率、电池及调零关系，Node另检验已声明边界。两篇核读全文、原报告给定的串联关系及上述独立推导支持当前已声明的简化理想教学场景；实际MF47厂商、子型号、内部支路参数和原DMM准确度不由这一教学场景反推。
