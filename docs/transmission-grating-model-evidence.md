# 透射光栅虚拟实验：模型、参数与验证依据

本稿给出有限透射光栅的全文依据、模型映射、参数身份和独立验证。参考文献：曾建华、彭亦平、赖徽媛、桑志文、常山，《夫琅禾费光栅衍射的MATLAB仿真及分析》，上饶师范学院学报2019，39(3)：26–30，DOI：[10.3969/j.issn.1004-2237.2019.03.006](https://doi.org/10.3969/j.issn.1004-2237.2019.03.006)。全文5页已核读，印刷页26–30均渲染查看，重点核对p27公式和代码、p28角度几何及p29缺级条件。

## 模型

均匀单色平面波正常入射等间距有限矩形缝阵列，忽略吸收、非均匀照明、缺陷、谱宽和探测器孔径。主极大满足 $d\sin\theta_m=m\lambda$。双侧同级谱线方位分别为 $-\theta_m,+\theta_m$，两个游标各取圆周角差后平均，再除以2求衍射角，用 $\lambda=d\sin\theta_m/m$ 反演。

光场直接计算单缝包络乘有限阵列复振幅模平方：$q=\pi d\sin\theta/\lambda$，$\beta=0.25q$，$I/I_0=(\sin\beta/\beta)^2[\sin(Nq)/(N\sin q)]^2$。整数q/π处使用连续极限；不将包络极小与阵列主极大混淆。

此式对应曾2019印刷p27式(1)–(3)：论文的$u$对应本项目$\beta$，论文的$v$对应$q$。论文以单缝轴向强度为基准；本项目除以$N^2$，归一化到整个阵列中央强度，因此中心值为1。主极大方向可由相邻缝相位差为整数$2\pi$推出，与p29式(6)的光栅方程一致。

适用模型为均匀照明、正常入射、同相同偏振的理想矩形缝标量夫琅禾费场；p26第1节给出准直与焦面观察装置。软件以衍射方向为横轴，不依赖论文的接收屏线坐标或焦距；不把此标量归一化曲线解释为真实亚微米开口光栅的矢量衍射效率、偏振响应或绝对光功率。大角度方向仍按正弦关系定位，但本模型没有额外倾斜因子、透镜像差和电磁边界求解。

## 参数

默认λ=546.1nm沿原报告绿线标定标准；d=2μm、N=20、开口比0.25是独立教学设定，未用原观测标定d作独立验证。开放d=1–4μm、λ=400–700nm、m=1–3、N=10–50。mλ≥d时无可传播该级主极大，页面阻止该级自动读数。窗口绘制±70°的有限阵列强度，高于70°的合法谱线仍可在360°测角盘定位。

圆周读数、零点及一阶反号谐波偏心模型与分光计组件一致。软件开口比、照明缝数没有源实测身份，不能解释为原光栅的真实分辨本领。

论文p27第2节的N=5、b=1μm、d=5μm、f=70mm、λ=632.8nm，以及各图中另选参数，均为该文的独立仿真场景，不替换本项目的546.1nm原绿线标准及d/N教学输入。p27式(4)是主极大附近的局部角宽近似，本页面不据此声称精确宽度，也不将接收屏线宽的焦距依赖转述成角分辨率随焦距改变。

## 数据身份及原观测

自动模型双侧谱线、用户实际望远镜选择的两方向、原报告20组谱线读数分别保存。原报告绿线标定d，紫/黄线依该d反演；绿线回代是恒等关系，不作为独立验证。部分两游标角差不一致保留，限制谱线定位和色散结论。

## 原文公式与代码核查

1. 印刷p27图1(b)代码的`xs(k)/sqrt(xs(k)+f^2)`分母缺少横坐标平方，量纲亦不相容；p28式(5)给出的几何关系为$x/\sqrt{x^2+f^2}$。本项目直接使用角度正弦和复孔径积分，没有复制该代码。
2. p27代码直接计算两个正弦商，没有为单缝中心和阵列整数相位显式给连续极限。本项目在$\beta\to0$处用级数，在$q\to k\pi$处对归一化阵列因子使用极限1；用独立逐缝复振幅求和及孔径积分校核。
3. p29式(6)明确单缝宽为$b$，但紧随其后的式(7)缺级分母印成$a$，与p26符号定义和图7的$d/b$不一致。由式(6)消去角度，应为$m=k'd/b$，$k'\ne0$。本项目包络宽度使用$b=0.25d$，可达的4倍数级出现包络零点；不是以不透光宽度$a$判缺级。
4. p28第3.4节及p30结论将焦距变化与“半角宽度”变化联系；在固定光栅、波长和照明条件下，角分布不依赖焦距，改变焦距改变焦面位置及线宽。本项目保留角度域强度，不采用该角宽表述。

核心强度和光栅方程已取得以上全文依据。对置游标一阶误差消除、双侧测角的仪器方法及原绿线标准身份仍分别由主DOCX与独立圆周几何推导支撑，后续实验教材核读定位单独登记；该篇仿真论文不被扩写为实际分光计校准或原装置参数认证。
