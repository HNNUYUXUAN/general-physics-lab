# 交流电桥：模型、参数与验证

## 模型依据

待测和标准电容均用串联有损阻抗。桥输出$U_G/E=Z_n/(Z_x+Z_n)-R_3/(R_4+R_3)$。实虚部同时归零给出$R_x=(R_4/R_3)R_n$、$C_x=(R_3/R_4)C_n$，损耗因数为$\omega R_xC_x=\omega R_nC_n$。

## 参数来源与适用范围

R3=10kΩ，Cn=0.10μF；默认Rx=194.4Ω、Cx=0.1/0.972μF由原第一组校准形成教学情景。损耗采用串联等效和频率无关参数，不把原指零增益当成精确物理放大倍数。

原报告CSV逐表保留在本页观测入口，来源路径和哈希沿原实验数据登记。模型教学值与原观测分别保存，不把原记录缺失值补成实测事实。

## 独立验证

81组情景用复数节点导纳矩阵求解两中点，验证实部、虚部及幅值；Node检查复平衡双条件、频率独立平衡及单独调节Rn不能补偿Cx失配。

检查结果和模型哈希见 [独立参考记录](simulation/ac-bridge-reference.json)。Node另检查解析算例、参数边界和所声明极限。

## 文献依据与拓扑映射

齐晓华、朱一博、史冬梅：《交流电桥原理与应用浅析》，渤海大学学报(自然科学版)，2021，42(3)：253–258。[DOI](https://doi.org/10.13831/j.cnki.issn.1673-0569.2021.03.011)。已核读六页全文，并检查p.254图1及式(1)–(9)的原排版。

p.254式(1)给出$Z_1Z_3=Z_2Z_4$；式(6)–(7)分别说明幅值与相位条件。页面将图1旋转并交换检测端标记，具体映射如下：

| 文献图1 | 本页面连接与符号 |
|---|---|
| 电源端$a,b$ | 上端$E$、下端$0$ |
| 检测端$d,c$ | 左中点、右中点；$U_G=V_d-V_c$ |
| 臂$Z_4$（$a$到$d$） | 左上待测串联有损电容$Z_x$ |
| 臂$Z_3$（$d$到$b$） | 左下标准串联电容$Z_n$ |
| 臂$Z_1$（$a$到$c$） | 右上纯电阻$R_4$ |
| 臂$Z_2$（$c$到$b$） | 右下纯电阻$R_3$ |
