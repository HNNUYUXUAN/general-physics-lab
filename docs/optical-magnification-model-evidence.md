# 光学放大与微小长度虚拟实验：模型、参数与验证依据

已核读马慧，《显微镜放大倍率的测定方法》，冶金分析与测试(冶金物理测试分册)1984(4)：29–30，DOI：[10.13228/j.boyuan.issn1001-0777.1984.04.010](https://doi.org/10.13228/j.boyuan.issn1001-0777.1984.04.010)。两页扫描全文实际阅读并渲染核看，机构题录未给卷号，省略该字段。另全文核读钟瑞、韩建卫、王拴、纪纬、张立彬，《视角直接比较法测自组望远镜放大率方法的改进》，大学物理实验2022，35(1)：13–15,24，DOI：[10.14139/j.cnki.cn22-1228.2022.01.003](https://doi.org/10.14139/j.cnki.cn22-1228.2022.01.003)，4页逐页渲染核看。马文支持标尺校准原则，钟文支持薄透镜与无穷远共焦望远镜；本页不同倍率定义与各文装置条件分开。

## 模型与操作

独立教学场景使用单个近轴薄透镜形成实像：$1/f=1/u+1/v$、$M=-v/u$。像面测微分划物理节距p对应物方每格值 $k=p/|M|$。先以已知L=0.100mm的标尺测得S格，实际标定值为 $k_{obs}=L/S$；再测细丝s格得到 $d=k_{obs}s$。网页要求先做同来源、同光学参数标定，再测细丝，不从隐藏设定k替代用户的标定读数。

马1984 p29第一节给放大像尺寸与被观察已知物镜测微尺长度之比；p30第二节第3项用1mm物镜标尺的实际投影长度$L_{image}$计算放大倍率$M=L_{image}/(1\,\mathrm{mm})$。其装置是250mm明视距离投影屏，不等同本页单薄透镜或目镜分划构造。本页仅采用“已知物长与像长比较”的校准关系：若固定像面分划节距p、已知物长L的像跨S格，则$|M|=pS/L$；待测细丝像跨s格，则$d=ps/|M|=Ls/S$，因而$k_{obs}=L/S$。这是明确光学条件下的独立消元，不声称论文直接提供本页数字分划装置。

望远镜另采用两正薄透镜共焦的开普勒近轴模型，角放大率 $M_T=-f_o/f_e$；负号表示倒像。它与源报告比较标尺的绝对放大率分别描述，不直接等同源仪器具体结构。

钟2022 p13第1节、图1和式(1)给两正透镜后/前焦面重合的无穷远近轴视角倍率绝对值$f_o/f_e$；图示为倒像，本页以负号保存方向。p14式(3)/(7)直接给薄透镜高斯关系$1/u+1/v=1/f$，横向倍率$M=-v/u$由通过光心的近轴主光线相似三角形独立求得，再由ABCD实现验证。望远镜用两薄透镜共焦的矩阵D取得有符号角倍率。原报告比较标尺实测并非本模型的无穷远输入，继续作为原观察独立呈现。

钟文p14第2–3节专门说明有限物距不能未经修正就使用无穷远倍率。本页望远镜只有无穷远共焦场景，未把有限物距测量硬套$f_o/f_e$。文中p15的物镜225mm、目镜45mm及各物距的测量批次不替换软件200/40mm及开放范围。马文肉眼角倍率以250mm明视距离定义，与本页像面横向倍率分别登记；不能拿其投影装置作为薄透镜/望远镜关系来源。

原文p14式(8)分母排印为多个因子乘积，量纲不符，已用300dpi原图核对。由其式(4)–(7)独立消元，有限物距倍率应为$\Gamma=u_1f_1/[u_1(L-f_1)-Lf_1]$；代入表1首行得约6.643，与表中6.64一致。本项目只采用式(1)/(3)/(7)和明确的无穷远限，没有实现或复制该错误有限物距表达式。

## 参数和范围

教学默认f=10mm、u/f=1.2、p=0.100mm、细丝0.050mm、望远镜物镜200mm、目镜40mm均为独立场景设定。范围f=10–30mm、u/f=1.1–1.5、p=0.05–0.20mm、细丝0.02–0.08mm、望远镜物镜100–300mm、目镜20–50mm。薄透镜近轴、无像差、无有限孔径和衍射分辨模型；不能把软件测微线步长0.01格当作真实仪器分度或分辨率。

## 数据身份和共享标定

自动理想与手动测微记录分别保存；标定与细丝记录通过kind区分。物距或分划改变后不能继续使用旧标定；改变细丝宽度不改变标定光学条件。共享标定误差不能按多次细丝观测再次缩小。

源报告四张表独立呈现，五次标定L/S先求均值，再用于所有细丝。原显微镜投影放大率、望远镜比较标尺放大率、标定与细丝的原记录保持同批次身份。未补造原焦距、物距、标尺校准或对焦系统误差。

## 独立验证

浏览器采用标量薄透镜公式；Python用ABCD传播矩阵，brentq求B=0的像面距离，以矩阵A取得横向放大率，再推分划比例。覆盖3焦距×3物距比×3分划节距的27场景。望远镜另做3物镜焦距×3目镜焦距9场景，用共焦系统C=0及矩阵D核验角放大率。Node验证已知算例、先标定后测量、参数变化重新标定、数据身份分组及非法焦距和反向读数。
