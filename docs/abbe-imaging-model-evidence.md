# 阿贝成像虚拟实验：模型、参数与验证依据

已取得并全文核读王力、施芸城、杨旭方、苗晓莉、崔博、王超梁、杨华政，《基于LabVIEW的阿贝4F系统成像实验的仿真设计》，大学物理实验2020，33(1)：85–89，DOI：[10.14139/j.cnki.cn22-1228.2020.01.021](https://doi.org/10.14139/j.cnki.cn22-1228.2020.01.021)，全文5页逐页渲染核看。该文p85–86给等焦距4f、复振幅与焦面物理坐标。另核读王橹为、陈宗强、孔勇发，《基于Python语言的阿贝成像原理与空间滤波实验的数字化改进》，物理与工程2025，35(2)：221–225，全文5页逐页渲染；该篇首页未给DOI，不猜填。数值DFT约定和采样条件由本项目显式推导及独立验证，不将论文图像网格当作认证。

## 二维复振幅成像

独立教学物体为4mm×4mm周期单元，幅透过率 $t(x,y)=0.5+0.2\cos(2\pi\nu x)+0.2\cos(2\pi\nu y)$，$\nu=N_c/4$。全域幅度0.1–0.9。理想相干4f系统的绝对放大率1，像方坐标按倒像方向翻转后与物方对齐，计算 $U_i=\mathcal F^{-1}[P\mathcal F(t)]$、$I_i=|U_i|^2$。傅里叶焦面物理坐标为 $\xi=\lambda f f_x$、$\eta=\lambda f f_y$。

王2025 p222第1节、式(2)/(3)给二维傅里叶正逆变换，正文将单色平面波照明后的后焦面分解及像面合成解释为阿贝两阶段。p223第2节、图2展示低通孔径作用；p224讨论狭缝方向与遮挡中央亮点的效果。其图1为单成像透镜实验，未给本项目两透镜4f配置、物理焦面比例系数或采样公式。这里采用等焦距理想4f作为独立教学系统：焦面Fraunhofer核 $\exp[-2\pi i(x\xi+y\eta)/(\lambda f)]$ 与二维FT核比较得 $f_x=\xi/(\lambda f)$；再由第二透镜作合成，去除共同全局相位并对齐倒像坐标，得上式。该推导与王2025已覆盖的相干分解/合成分开登记；新核读王力2020的专项4f光路和物理坐标补足这一模型依据，见下段。

王文p223以灰度图直观描述强度与滤波，未给数值源代码或明确复相位算法。本模型始终对复振幅乘孔径，完成逆变换后才取模平方；频谱显示的对数灰度不参与成像计算。文献1000²校徽/二值字母光栅及激光雕刻材料、实验图样不被复制为本项目观测或验证数据。

王力2020 p85第1节明确以单色相干平面波照明幅透过率，并给后焦面复振幅的二维FT及 $u=\xi/(\lambda f)$、$v=\eta/(\lambda f)$；p86图1标四段相等f，物面、频谱面及像面分明。p87第3.1节为圆环高/低频选择，p88第3.2节图8–9为正交方向滤波，与本项目物理孔径选择对应。

王力文p85第二个未编号变换公式写正指数，却在末尾等同$T_P(-x,-y)$，与前面负指数FT约定不自洽，且空间/频率变量混用。本实现按两次同号物理FT产生倒像、再将像坐标翻转与物方对齐后使用逆FFT的明确约定；全通复场恢复、Parseval与独立NumPy核验确认。p86称全通图像颜色相反是该程序显示，不能当作相干全通强度普遍反相的物理结论。

前向FFT不归一化，逆向每维除N；边界为周期边界。物体周期数限制为整数，避免把不整周期的边缘跳变误当原物体高频。孔径包括全通、圆孔、零级小孔、横/竖窄狭缝、遮零级；小孔半径及狭缝半宽固定0.05mm。像/物图共用线性强度0–0.81显示，频谱单独采用log(1+强度)显示，其亮度不可与物像直接比较。

## 参数与采样

默认λ632.8nm与f150mm来自原配置；L4mm、16周期正交光栅、圆孔0.4mm与振幅系数为独立教学场景，不由原观测频谱或可见度重建。λ500–700nm、f100–200mm、周期数8–32、圆孔0–2mm，网格128/256/512。最高幅度频率8mm⁻¹；最粗网格Nyquist16mm⁻¹、至少4幅度采样点/周期，强度包含二次谐波，256²为默认显示和计算网格。

采样判据来自独立DFT关系：$\Delta x=L/N$，频率间隔$\Delta f=1/L$，Nyquist频率$N/(2L)$。幅透过率只有$(0,0)$、$(\pm\nu,0)$、$(0,\pm\nu)$五个谱点；整数$N_c$保证落在频率格点，最高$N_c=32$仍小于最粗N128的半网格64，故复场频谱不混叠。孔径只选择已有谱点，不生成更高复场频率。强度模平方含二次谐波，N128且$N_c=32$时最高强度频率恰到Nyquist，只作为该已定义物体的离散强度取样，不宣称可唯一重建任意相位的连续强度；默认N256及更密网格给二次谐波留有余量。两篇文献没有给该采样判据，项目不引用其示例图像大小代替推导。

模型忽略像差、偏振、非相干照明、实际光阑边缘制造和探测器响应。频谱遮零级后强度的相位关系由真实复场决定，不预置“普遍反相”标签。

## 数据与记录

原报告频谱五位置与五种滤波观察独立呈现；没有实测频谱复振幅、光阑尺寸及可见度最大最小强度，不能重建原二维物像。模型结果与用户像素取样分别标为ideal-model/manual-probe，记录保存全部参数、实际像素及物方坐标、复振幅、模平方和派生能量/可见度。数组由参数与FFT版本复现。

## 独立验证

浏览器使用自实现radix-2二维复FFT；Python用NumPy FFT2，独立构建物理焦面孔径，逐像素比较完整复振幅。覆盖3周期数×3波长×3焦距共27场景并轮换六种孔径；3代表场景加倍网格128→256，在共同物方采样位置检验收敛。

Node另用解析傅里叶系数和Parseval检验：全通能量比例1，仅零级0.25/0.29，窄水平狭缝0.27/0.29，遮零级0.04/0.29；零级像强度0.25。初次独立最大复场误差7.78×10⁻¹⁶，能量比误差5.38×10⁻¹⁴，加倍网格共同点误差9.36×10⁻¹⁶。哈希包括模型与FFT公共实现，验证JSON记录环境与容差。
