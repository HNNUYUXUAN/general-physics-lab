# 示波器调节与使用：模型、参数与验证

## 模型依据

游标分别以垂直格数、水平格数读取，$U_{pp}=|\Delta y|S_V$，$T=|\Delta x|S_t$，有效值由零偏置对称波形的积分定义确定；正弦、三角和方波分别为峰值除以$\sqrt2$、$\sqrt3$和1。

## 参数来源与适用范围

默认峰值0.5V、1000Hz沿原报告示意值；游标由用户设置，测得结果与已知输入分别保留。屏幕为10×8格，若信号超过可显示幅值，页面明确提示裁切。XY相位和频率比为教学设定。

原报告CSV逐表保留在本页观测入口，来源路径和哈希沿原实验数据登记。模型教学值与原观测分别保存，不把原记录缺失值补成实测事实。

## 独立验证

27种波形、幅值和频率组合以独立数值能量积分检查有效值；游标格数换算独立核对。Node检查波形极值、RMS关系、屏幕裁切及零周期游标状态。

检查结果和模型哈希见 [独立参考记录](simulation/oscilloscope-reference.json)。Node另检查解析算例、参数边界和所声明极限。

## 文献依据与范围

伍泓锦、段阳、杨浩林、樊代和、贾欣燕：《基于李萨如图形的精确测量初相位差研究》，物理实验，2019，39(12)：50–53。 [DOI](https://doi.org/10.19655/j.cnki.1005-4642.2019.12.011)。全文已逐页核读，并查看关键公式的原页渲染。

p.51式(1)采用两个正交正弦参数轨迹。项目明确以赫兹输入，写成

$$u_x=A\sin(2\pi f_xt),\qquad u_y=B\sin(2\pi f_yt+\varphi).$$

原文函数中的$p,q$在量纲上对应角频率，映射为$p=2\pi f_x$、$q=2\pi f_y$。项目XY图取$B=A$、$f_y=1000\ \mathrm{Hz}$、$f_x/f_y$为所选比值，显示4 ms完整共同周期；这些是独立教学输入。用户设置的$\varphi$以度输入，代码乘$\pi/180$计算，表示以$x$信号初相位为零时的$y$初相位参数。时域显示的输入频率另由频率控件给定。

p.51式(2)的包围盒长度是峰峰值，振幅为其一半，与$U_{pp}=|\Delta y|S_V$一致。式(3)支持简单频率比与切点计数的联系；本页直接按已知频率比生成轨迹，没有把自动绘图当成切点测量。

同一静态李萨如轨迹可能对应多个初相位。p.51式(4)中主值$\arcsin(x/A)$只覆盖局部分支，页面使用完整时间参数轨迹。用户给定相位与从图形测得相位是不同的量；要对实验中的多解消歧，需要同步时域相位或有方向、时间基准的轨迹等额外信息。当前静态XY图不输出唯一的相位反演结果。

论文2 kHz/3 kHz、2.4 V/1.6 V和$\pi/6$属于其验证批次。项目0.5 V、1000 Hz沿原报告示意值，其余控件是教学设置。正弦、三角、方波有效值由$U_{\mathrm{rms}}^2=T^{-1}\int_0^T u^2\,dt$独立积分，论文并不提供这些波形的仪器校准。
