# 棱镜顶角虚拟实验：模型、参数与验证依据

装置依据为刘文晶、杨文革、金武、王心华、张水合，《改进反射法测三棱镜顶角实验的思考》，大学物理实验2023，36(2)：77–80，DOI：[10.14139/j.cnki.cn22-1228.2023.02.017](https://doi.org/10.14139/j.cnki.cn22-1228.2023.02.017)。全文4页实际核读，p78–79与图2已渲染核看；图2另以高分辨率核对。双游标读数程序另参照徐崇，《用掠入射法测量透明介质折射率的探讨》，大学物理实验2009，22(1)：9–13，DOI：[10.14139/j.cnki.cn22-1228.2009.01.005](https://doi.org/10.14139/j.cnki.cn22-1228.2009.01.005)，全文5页及p10–12数学页已核看。

同一平行入射束分别被两个棱镜面反射，每个方向遵守 $\mathbf r_j=\mathbf i-2(\mathbf i\cdot\mathbf n_j)\mathbf n_j$。法线为无向轴，反射不随法线正负改变；由单位向量点积独立得到 $\mathbf r_1\cdot\mathbf r_2=\cos(2A)$，在本实验开放A=40–80°内，两反射方向的最短夹角为2A。模型保存两个方向的双游标读数，先平均圆周角差，再除以2求顶角。一阶反号谐波偏心教学模型和跨零读角保留独立假设身份。

刘2023 p78–79第2节、图2实际给同一平行束覆盖棱镜两个面、分别观察反射狭缝像的装置，讨论顶角靠近平台中心的位置。该图没有直接标注2A，正文未给倍角关系的编号公式；本项目倍角结果来自上述独立反射推导及Python数值验证。p77区分自准直法与反射法，因此不将自准直A=180°−φ的方位定义混入本方法。p78第1节有关望远镜轴线、调节和视场的三维过程未纳入本二维光路。

默认A=60°、刻度零点10°、偏心幅度5′为独立教学场景；A范围40–80°，使两反射方向最短夹角80–160°。零点0–360°、一阶幅度0–10′。角度显示和望远镜滑动分辨率是软件约定，不代表实际仪器分度；未重建自准直、水平调节的三维机械过程。

原报告5组四游标读数由源CSV独立读取；每一游标先取跨零最短差，再计算 $(|\Delta v_1|+|\Delta v_2|)/4$。源报告角度误差限1′的用法单独保留，不把教学扰动幅度等同该误差限。

浏览器使用双游标圆周差计算；独立Python从两个镜面法线向量计算反射光线，再求单位向量夹角，另用单位复数商的相位核验角差。覆盖3顶角×3零点×3偏心幅度的27场景。Node覆盖反射倍角、跨零偏心抵消、手动读数及边界。
