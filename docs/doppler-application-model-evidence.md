# 多普勒应用：模型、参数与验证依据

## 装置与模型

原报告是固定超声发射源、随弹簧振子运动的接收器，保存静态载荷和13个周期；本页沿此配置，不套反射双程或驻波测速。介质静止，向下接近声源为正，$f_{rec}=f_0(1+v/u)$。

机械位移围绕重力平衡位置，均匀轻弹簧有效质量近似 $M_{eff}=M+m_s/3$：$x=A\cos\omega t$，$\omega=\sqrt{k/M_{eff}}$。固定声源的接收相位由传播距离决定，差相位 $\Delta\phi=2\pi f_0x/u$，其导数给出有向频移。单个实余弦混频信号可能丢失方向，本页直接展示有向频移，不冒称用未给定仪器电路完成解调。

周期测标选相邻同向峰，动态反演同时列忽略弹簧质量及包含有效质量两式。静态额外质量使位置变化mg/k，位置基线已经包含装置预载。

假定弹簧线弹性、无阻尼、单自由度，接收器始终沿声线。mₛ/3依均匀弹簧近似，没有用该修正解释原动态值较大的成因。原13周期及5静态点独立保留，源第1点剔除状态和全点敏感性并列；原时序、计时器误差限和弹簧质量均缺失。

## 验证

Python独立DOP853积分振子，利用同向速度零点事件测周期；对移动接收器传播距离的延迟相位数值求导，比较频率和位移速度。Node检查守恒、接收频率单程系数、相位导数、弹簧质量修正方向和静态偏移。结果见 `docs/simulation/doppler-application-reference.json`。
