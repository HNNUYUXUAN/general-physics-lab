# 线膨胀：模型、参数与验证依据

## 模型

工程线膨胀关系 $\Delta L=\alpha L_0(T-T_0)$ 采用常数系数，千分表 $S=S_0+G\Delta L$、温度读数 $T_{ind}=T+b_T$。斜率 $k$ 除以指定参考长度给出表观系数。

均温杆升温用独立教学的一阶模型 $\dot T=(T_{set}-T)/\tau$ 表示，初始20℃。有限时间运行到5τ仍不严格平衡；“设定平衡状态”明确计算稳态。该时间常数为教学输入，未与原加热器输入功率或具体材料热容对应。

## 原资料与验证

八组原报告值与配套讲义B示例逐项一致，保留示例身份。回归和四组逐差均从原字符记录复算；没有将其计为新增独立测量。原有效长度与仪器系统误差缺失，残差传播分量不代表完整不确定度。

Python用DOP853独立积分升温ODE，在0、0.5、1、3、5τ比较温度；再积分沿杆长的热应变求伸长，检查偏移和增益条件的系数回归。Node检查初始、渐近、ODE差分、长度缩放、零点抵消、增益偏差和混合场景拒绝。结果见 `docs/simulation/thermal-expansion-reference.json`。

## 全文核读

唐军杰、杨翼、肖鸿宇、缪俊茜、赵昆、王爱军、吴冲：《光杠杆法测定金属的线胀系数》，现代科学仪器2012(6)：155–156。尚未确认DOI。全文两页已按PDF渲染逐页核读；PDF字体映射使自动提取文本乱码，公式及作者以渲染原页核对。

p155§1.1式1–2为小温区常系数线膨胀关系；式3–4将光杠杆读数换算伸长，p156图1给几何关系，§2使用N–T最小二乘斜率。该文采用水浴加热铜丝、光杠杆放大，原报告当前采用数字位移/千分表；本页只复用均温线膨胀和温度斜率关系，不把光杠杆H/(2D)系数移到千分表增益G。

论文约29.6–70.3℃的铜丝数据及17.1×10⁻⁶K⁻¹转引参考不替换本项目150mm杆和讲义示例，也不证明本软件30–110℃全部材料恒α。当前α为指定教学常量。论文不含一阶升温动力学；本页τ是独立均温一阶状态模型，其公式适用条件与DOP853检验单独列明，未据该论文声称具体仪器已辨识τ。


## 一阶升温公共依据

蔡晨等，大学物理2016，35(5)：53–56，DOI：[10.16854/j.cnki.1000-0712.2016.0080](https://doi.org/10.16854/j.cnki.1000-0712.2016.0080)，p53式4–5和p54式7–8给牛顿冷却微分式及精确指数解。取集中热容$C_{eff}$、线性换热H和恒温热浴$T_b$，独立导出$C_{eff}\dot T=H(T_b-T)$、$\tau=C_{eff}/H$。该假设要求内部均温、常物性和恒浴温；本页τ=15s为教学输入，不采用论文量热器K。热膨胀论文提供水浴均温场景，两者共同界定本页状态模型，未声称真实金属杆的集总假设经Biot数实测确认。
