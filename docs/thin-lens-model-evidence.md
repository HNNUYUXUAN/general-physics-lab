# 薄透镜：模型、参数与验证

## 近轴模型和符号

空气中零厚度薄透镜、近轴传播、忽略像差。凸透镜 $f>0$，实物距 $u>0$，实像距 $v>0$，虚像 $v<0$：

$$1/f=1/u+1/v,\qquad v=fu/(u-f),\qquad M=-v/u.$$

在 $u=f$ 时出射光平行，无有限像距。页面显式给出平行状态，不以大有限数替代。辅助凹透镜原记录为虚物距 $u=-a$、实像距 $v=b$，故 $f=-ab/(b-a)$。

## 二次成像与临界

固定物屏距离 $D=u+v$，解薄透镜关系得到

$$u_{1,2}=(D\mp\sqrt{D^2-4Df})/2,\qquad d=|u_2-u_1|,\qquad f=(D^2-d^2)/(4D).$$

$D>4f$ 有两个不同位置，$D=4f$ 合并为 $u=v=2f$，$D<4f$ 无实位置。移动透镜时用两条不同入射角的主光线在光屏上的高度差显示离焦；清晰位置由高度差为零确认。

## 独立验证

浏览器使用共轭公式及逐光线折转。Python 使用 NumPy 构造自由传播与透镜 ABCD 矩阵：$P(d)=\begin{pmatrix}1&d\\0&1\end{pmatrix}$、$L(f)=\begin{pmatrix}1&0\\-1/f&1\end{pmatrix}$，验证 $P(v)L(f)P(u)$ 的 $B=0$ 及其 $A$ 元等于放大率。

三种焦距、六个物距比（包括0.99、1、1.01）与五种物屏距离比（包括4、4.0001）共90组。检查实像、虚像、平行、无二次成像、单位置和双位置。矩阵量绝对容差 $10^{-11}$；具体结果见 [独立参考记录](simulation/thin-lens-reference.json)。
