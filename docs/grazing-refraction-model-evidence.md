# 掠射折射率虚拟实验：模型、参数与验证依据

液体掠射模型及双游标步骤已有专项全文依据：徐崇，《用掠入射法测量透明介质折射率的探讨》，大学物理实验2009，22(1)：9–13，DOI：[10.14139/j.cnki.cn22-1228.2009.01.005](https://doi.org/10.14139/j.cnki.cn22-1228.2009.01.005)。全文5页已核读，p10–12的光路、公式与读数表已渲染核对。另有谭锦博、吴秀梅，《三种测量三棱镜折射率方法的讨论》，物理与工程2024，34(3)：172–177，作为掠射基础及不同装置的比较文献；其约60°空气至玻璃装置不与当前90°液体装置混用。

## 模型与范围

透明液体至高折射率直角棱镜，第一面入射取理想掠射90°。第一面Snell关系 $n=n_1\sin\beta$，两面夹角90°给出 $\gamma=90^\circ-\beta$，出射至空气满足 $\sin\varphi=n_1\sin\gamma$。消去内部角得到 $n=\sqrt{n_1^2-\sin^2\varphi}$。

徐2009 p9末及p10式(1)–(3)、图1–2直接给液体至已知棱镜、再向空气出射的掠射光路。p11式(4)/(6)给一般顶角的两个支向，90°时余弦项为零。对本装置分别记液体$n_\ell$、棱镜$n_p$、出射介质$n_e$，由$n_\ell=n_p\sin\beta$、$n_e\sin\varphi=n_p\cos\beta$得到$n_\ell^2=n_p^2-n_e^2\sin^2\varphi$，再令$n_e=1$。该推导与文中一般顶角式的90°极限一致。

论文p11式(7)印成$n=n_1^2-\sin^2\varphi$，遗漏平方根，与其式(4)/(6)的90°极限不一致。本项目使用上述逐面Snell消元的正根，并由两次独立数值求根核验，未照抄排印错误。

默认液体n=1.33为独立教学设定，棱镜n₁=1.5425来自源配置；未指定材料牌号和波长，不将模型扫参解释为真实材料色散。范围n=1.25–1.45，n₁=1.50–1.55，保证 $0<n_1^2-n^2<1$ 与可出射条件。软件未包含有限角宽、接触层、温度依赖、表面误差及吸收。显示光线与参考法线夹角来自计算值，棱镜图为测角示意。

徐2009采用钠光，实际表1是60°棱镜n₁=1.648测丙三醇；p11明确讨论90°特例，并未提供本装置n₁=1.5425的材料/波长校准。谭2024的钠灯、辅助棱镜、参考n=1.6500及FGY仪器30角秒分度也不替换当前条件。论文的材料示例值仅保留其批次身份。明暗边界是掠射极限的定位依据，页面只描画极限光线，未计算实际光束角分布、散射或辅助棱镜边界对比度。

## 记录与原资料

用户实际望远镜读数与理想对准记录分身份保存；双游标求有向最短角差平均后取出射角。刻度零点与反号一阶谐波误差是独立教学扰动，不代表完整仪器校准。源报告5组角度及n₁=1.5425、指定分量0.0006独立处理，源报告不确定度说明保持其适用条件。

## 测角与证据范围

徐2009 p11第2节步骤(3)–(4)分别读取明暗边界、出射面法线的两游标；式(8)以两个方位差的绝对值平均求$\varphi$。本页面保留两游标分别求差及平均的过程，并用圆周有向最短差处理跨零后取绝对值；软件范围内两游标差同向，避免把360°跳变当物理夹角。一阶反号谐波误差消除是所声明扰动模型下的独立代数结果，不把论文的双游标操作认作实际仪器完整校准。

徐文的定义是由出射光线到AC面法线的角度；本页面采用同一物理出射角。谭2024式(5)/(7)在两侧空气的不同几何下使用，本页不照搬；其p175式(20)的p偏振幅度正弦比也未采用。本文献核读确认装置基本关系与读数方法，材料实际折射率、温度/波长依赖及完整仪器不确定度仍按原记录的适用范围说明。
