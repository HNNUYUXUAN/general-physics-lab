# 虚拟实验

4门课程，45项在线虚拟实验。从装置操作到读数分析，按课程或物理问题选择实验。

[打开在线目录：搜索与筛选](https://hnnuyuxuan.github.io/general-physics-lab/simulations/) · [按物理主题浏览](https://hnnuyuxuan.github.io/general-physics-lab/simulations/?group=topic)

## 按课程进入

### 普通物理实验 1 · 8项

运动、波动与热量测量。 [在线筛选本课程](https://hnnuyuxuan.github.io/general-physics-lab/simulations/?course=course-01)

- [单摆测重力加速度](https://hnnuyuxuan.github.io/general-physics-lab/simulations/pendulum/)：重复计时、周期与摆长拟合。 [模型与文献](../docs/pendulum-model-evidence.md)
- [多普勒效应的验证](https://hnnuyuxuan.github.io/general-physics-lab/simulations/doppler-verification/)：运动接收器、频率读数与速度反演。 [模型与文献](../docs/doppler-verification-model-evidence.md)
- [多普勒效应的应用](https://hnnuyuxuan.github.io/general-physics-lab/simulations/doppler-application/)：往复运动、频移与速度恢复。 [模型与文献](../docs/doppler-application-model-evidence.md)
- [牛顿第二定律的验证](https://hnnuyuxuan.github.io/general-physics-lab/simulations/newton-second-law/)：悬挂驱动、光电门测速与加速度。 [模型与文献](../docs/newton-second-law-model-evidence.md)
- [碰撞规律的研究](https://hnnuyuxuan.github.io/general-physics-lab/simulations/collisions/)：碰前碰后光电门测速、动量与恢复系数。 [模型与文献](../docs/collisions-model-evidence.md)
- [热功当量的测量](https://hnnuyuxuan.github.io/general-physics-lab/simulations/mechanical-equivalent-heat/)：电热升温、环境散热与热功当量。 [模型与文献](../docs/mechanical-equivalent-heat-model-evidence.md)
- [物质密度的测量](https://hnnuyuxuan.github.io/general-physics-lab/simulations/density/)：称量、几何测量、液体浮力与密度。 [模型与文献](../docs/density-model-evidence.md)
- [液体比汽化热的测量](https://hnnuyuxuan.github.io/general-physics-lab/simulations/vaporization-heat/)：混合量热、称量测温与汽化热。 [模型与文献](../docs/vaporization-heat-model-evidence.md)
